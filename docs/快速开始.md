# 快速开始

**中文** · [English](QuickStart.md)

从零到一个能跑的锤子风格页面大约 10 分钟。本文每一步都给可以直接复制的代码，
代码与 `sample` 模块里的实现一致；想深入某个主题，每节末尾都指向对应文档。

> 只想先看看效果？直接跳到[第 0 节](#0-先跑示例应用)，三条命令就能装到手机上。

## 0. 先跑示例应用

```bash
git clone https://github.com/xiaomianguan/smartisanx.git
cd smartisanx
./gradlew :sample:installDebug      # 也可以 :sample:assembleDebug 之后自己 adb install
```

示例应用是本库的「活文档」：13 个组件页（主题、文字、图标、按钮、基础控件、文本与输入、
布局与列表、整页布局、列表交互、浮层、时钟与机械控件、日历、关于），
其中「整页布局」是 13 张完整页面，每张都能直接复制当起点。

APK 约 45MB —— 因为锤子风格是拟物设计，质感全靠原版位图与 NinePatch（共 10485 个资源文件），
不是用 Compose 重画的。这一点在下文「打包与体积」里再展开。

## 1. 环境要求

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| minSdk | 26（Android 8.0） | |
| compileSdk | 37 | 库依赖 Compose 1.12，消费方不能低于 37 |
| Kotlin | 2.4 | 需要 Compose 编译器插件 |
| Compose BOM | 2026.09.00 及以上 | |
| AGP / Gradle / JDK | 9.4 / 9.8 / 17 及以上 | AGP 9 起 Kotlin 编译由 AGP 内置支持，模块里不用再声明 `kotlin-android` |

本库**不依赖 Material / Material3**。如果你的项目同时用 Material，两者可以共存，
但 smartisanx 组件必须包在 `SmartisanTheme` 里，而不是 `MaterialTheme` 里
（原因见[常见问题](#13-常见问题)）。

## 3. 包上主题

**所有组件都必须放在 `SmartisanTheme` 内**，否则会抛出明确的异常提示
（「未找到 SmartisanColors」），而不是静默用错颜色：

```kotlin
setContent {
    // 默认就是浅色，与原版 Smartisan OS 一致
    SmartisanTheme {
        App()
    }
}
```

`SmartisanTheme` 同时提供三件事：色板、文字样式与形状；它还把**滚动越界回弹**
换成了原版行为（刚性平移 + 弹簧回弹，不是 Material 的拉伸），所以页面里的
`LazyColumn` / `Modifier.verticalScroll` 不用做任何额外配置。

## 4. 第一个页面

```kotlin
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        // 内容延伸到系统栏底下；Insets 由各组件自行处理
        WindowCompat.setDecorFitsSystemWindows(window, false)
        setContent {
            val controller = rememberSmartisanThemeController()
            SmartisanTheme(controller) {
                SmartisanScaffold(
                    titleBar = {
                        SmartisanTitleBar(
                            title = "我的应用",
                            navigationIcon = SmartisanTitleBarAction(
                                iconRes = SmartisanOriginalIcons.Back,
                                contentDescription = "返回",
                            ) { /* 返回 */ },
                            actions = listOf(
                                SmartisanTitleBarAction(
                                    iconRes = SmartisanOriginalIcons.More,
                                    contentDescription = "更多",
                                ) { /* 打开菜单 */ },
                            ),
                        )
                    },
                ) {
                    SmartisanListVerticalGap()
                    SmartisanSectionTitle("第一组")
                    SmartisanGroup {
                        SmartisanGroupItem(
                            position = SmartisanGroupRowPosition.Top,
                            title = "第一行",
                            summary = "说明文字",
                            leading = {
                                SmartisanIcon(
                                    res = SmartisanOriginalIcons.Settings,
                                    contentDescription = null,
                                )
                            },
                            trailing = { SmartisanListRowArrow() },
                            onClick = { /* ... */ },
                        )
                        SmartisanGroupItem(
                            position = SmartisanGroupRowPosition.Middle,
                            title = "开关项",
                            showDivider = true,
                        )
                        SmartisanGroupItem(
                            position = SmartisanGroupRowPosition.Bottom,
                            title = "最后一行",
                        )
                    }
                }
            }
        }
    }
}
```

这段代码里有四个「必须知道」：

1. **`SmartisanTheme` 必包**，见上一节。
2. **`SmartisanScaffold` 默认已经是原版页面**：整页是 `common_bg` 细条纹底纹，
   标题栏自带状态栏占位与栏外投影，系统导航栏那条留白也由它负责。
   传 `backgroundRes = null` 退回纯色，传 `applyNavigationBarInset = false` 自己管 Insets。
3. **内容区自己不滚动**：要滚动就在里面放 `Modifier.verticalScroll(...)` 或 `LazyColumn`，
   同时给骨架传 `contentScrollable = true` —— 内容于是能一直画到屏幕最底下
   （透明导航栏下能看到列表），导航栏那条留白改由内容补在**滚动内容的末尾**
   （`LocalSmartisanContentBottomInset`），滚到底时最后一行不会被导航栏挡住。
4. **`SmartisanGroupItem` 必须传 `position`**：原版把分组卡片拆成上 / 中 / 下 / 单张
   四段底图，圆角只出现在首尾，所以每一行都要知道自己是哪一段（下一节详解）。

## 5. 页面里怎么摆内容：卡片、行、留白

原版页面的结构是「条纹底纹 + 一张张白色卡片」，卡片的白底、圆角与向外投影都由
**每一行自己的 NinePatch** 提供，分组容器本身是透明的。于是有两条硬规则：

1. **相邻两个分组之间插一条 `SmartisanListVerticalGap()`**（14dp，对应原版
   `list_item_vertical_gap`）—— 两张卡片的投影正好落在这段留白里互相重叠。
   分组标题 `SmartisanSectionTitle` 前后**不用**插，它自带留白。
2. **分组里的行必须传 `position`**（`SmartisanGroupRowPosition` 的
   `Top` / `Middle` / `Bottom` / `Single`），它决定取哪一段卡片底图（圆角只在首尾）。

| 你的需求 | 用什么 |
| --- | --- |
| 分组里的一行（多行拼成一张卡片） | `SmartisanGroupItem(position = ...)` |
| 单独一行（自带整张卡片底图与投影） | `SmartisanListItem` |
| 需要 2 / 3 行文字的自适应版式 | `SmartisanListRow`（`lines = SmartisanListRowLines.TwoLine` 等） |
| 分组里的内容不是列表行（控件排排站、自定义块） | `SmartisanGroup(position = SmartisanGroupRowPosition.Single) { ... }` |
| 行与行之间的分隔线 | 行传 `showDivider = true`，或用 `SmartisanRowDivider()` / `SmartisanGroupDivider()` |
| 独立卡片（天气、专辑那种块） | `SmartisanCard { ... }` |

开关与单选也有现成的行：`SmartisanSwitchRow(text, checked, onCheckedChange)`、
`SmartisanRadioRow(text, selected, onClick)`，直接放进分组即可
（`SmartisanSwitchRow` 还能直接传 `position`）。

```kotlin
SmartisanScaffold(titleBar = { SmartisanTitleBar(title = "设置") }) {
    Column(Modifier.verticalScroll(rememberScrollState())) {
        SmartisanListVerticalGap()
        SmartisanSectionTitle("通知")
        SmartisanGroup {
            SmartisanGroupItem(SmartisanGroupRowPosition.Top, "允许通知")
            SmartisanGroupItem(SmartisanGroupRowPosition.Middle, "锁屏显示", showDivider = true)
            SmartisanGroupItem(SmartisanGroupRowPosition.Bottom, "通知铃声")
        }
        SmartisanListVerticalGap()
        SmartisanSectionTitle("通用")
        SmartisanGroup {
            SmartisanGroupItem(SmartisanGroupRowPosition.Single, "语言与输入法")
        }
        SmartisanListVerticalGap()
    }
}
```

> 分组自己为什么不留纵向间距？原版那 14dp 是**插在两个分组之间**的一条空白 View，
> 不是分组的内边距 —— 实测数据见[主题与设计变量](主题与设计变量.md)。

## 6. 第二个页面：转场与返回

库自带原版转场（常规页面从右侧滑入、模态页面从底部滑入），不依赖任何导航库：

```kotlin
var detail by remember { mutableStateOf(false) }
SmartisanPageTransition(
    secondary = detail,
    primary = { HomeScreen(onOpen = { detail = true }) },
) {
    DetailScreen(onBack = { detail = false })
}
```

模态页（例如「新建播放列表」）用底部滑入：

```kotlin
SmartisanModalPageTransition(visible = showModal) { ModalScreen() }
```

子页面自己负责返回：标题栏左键 + 系统返回键。

```kotlin
BackHandler(enabled = detail) { detail = false }
SmartisanTitleBar(
    title = "详情",
    navigationIcon = SmartisanTitleBarAction(SmartisanOriginalIcons.Back, "返回") { detail = false },
)
```

## 7. 长列表

```kotlin
val listState = rememberLazyListState()
LazyColumn(
    state = listState,
    modifier = Modifier.fillMaxSize().smartisanVerticalScrollbar(listState),
) {
    item { SmartisanListVerticalGap() }
    items(songs, key = { it.id }) { song ->
        SmartisanListItem(
            title = song.title,
            summary = song.artist,
            onClick = { /* ... */ },
        )
    }
    item { SmartisanListVerticalGap() }
}
```

- 滚动越界回弹已经是原版行为（刚性平移 + 弹簧回弹），不用配置；
- `Modifier.smartisanVerticalScrollbar(state)` 画原版滚动条，`ScrollState` 与
  `LazyListState` 都有重载；
- 拖动排序：`SmartisanReorderableColumn(items, onMove) { index, item, dragging -> ... }`；
- 侧滑删除：`SmartisanSwipeToDelete(onDelete = { ... }) { row }`；
- 字母索引：`SmartisanLetterIndexBar(letters, onLetterSelected = { ... })`；
- 空列表：`SmartisanEmptyHint(title, description = ..., actionText = ..., onActionClick = ...)`。

## 9. 深浅色（实验性）

**默认浅色，与原版一致。**「跟随系统」与「深色」必须显式开启，并由你自己向用户说明
—— 原版只有浅色一套设计，深色由三个复刻项目新增，而且原版图形资源里只有约 2.5%
带夜间变体（详见[主题与设计变量](主题与设计变量.md#深色模式实验性)）。

```kotlin
val controller = rememberSmartisanThemeController(SmartisanColorSchemeMode.System)
SmartisanTheme(controller) { /* ... */ }

controller.colorSchemeMode = SmartisanColorSchemeMode.Light   // 默认
controller.colorSchemeMode = SmartisanColorSchemeMode.System  // 跟随系统（实验性）
controller.colorSchemeMode = SmartisanColorSchemeMode.Dark    // 深色（实验性）
```

同时建议把系统栏图标一起切换：

```kotlin
val view = LocalView.current
val isLight = LocalSmartisanColors.current.isLight
SideEffect {
    val window = (view.context as Activity).window
    val insets = WindowCompat.getInsetsController(window, view)
    insets.isAppearanceLightStatusBars = isLight
    insets.isAppearanceLightNavigationBars = isLight
}
```

## 10. 图标与素材

图标**不用自绘矢量集**，直接用原版素材（selector 自带按下 / 禁用态）：

| 对象 | 用途 |
| --- | --- |
| `SmartisanOriginalIcons` | 按用途命名的常用图标：`Back`、`More`、`Search`、`Settings`、`Delete`、`Play`…… |
| `SmartisanDrawables` | 组件默认使用的图形资源（标题栏、弹窗、分组底图、表盘……），也可以直接拿来用 |
| `SmartisanIconSet` | 从原厂 APK 提取的 3617 个图标总表，分 9 组，按组浏览 |

```kotlin
// 命名图标
SmartisanIcon(res = SmartisanOriginalIcons.More, contentDescription = "更多")

// 总表里的一组（例如「列表行图标」那一组）
SmartisanIconSet.listRow.icons.forEach { entry ->
    SmartisanIcon(res = entry.res, contentDescription = entry.name)
}

// 原版没有对应素材时，用自己画的矢量图
SmartisanIcon(imageVector = myImageVector, contentDescription = null)
```

## 11. 多语言

- 库内所有用户可见文案都已资源化：22 条字符串里 19 条带 AOSP 的 80 种语言译文，
  后加的 3 条（日历「今天」、手势提示的标题与正文）目前有简体中文、繁体中文、日文、韩文，
  其余语言回落英文。
- 组件默认跟随系统语言，你不需要做任何事。
- 你自己的文案照常放在自己模块的 `values-*/strings.xml` 里。

想锁定语言（例如做演示截图）可以覆盖 `attachBaseContext`：

```kotlin
override fun attachBaseContext(newBase: Context) {
    val locale = Locale.SIMPLIFIED_CHINESE
    Locale.setDefault(locale)
    val config = Configuration(newBase.resources.configuration).apply { setLocale(locale) }
    super.attachBaseContext(newBase.createConfigurationContext(config))
}
```

## 12. 打包与体积

- **体积主要来自原版素材**：`library/ui/src/main/res` 里共 10485 个资源文件，
  debug 包约 45MB。R8 只影响代码、不影响资源 —— 想瘦身就删掉用不到的
  `drawable*` 目录，或只保留自己用到的素材（组件的素材入口都是参数，可以换成你自己的图）。
- **代码侧不需要额外 ProGuard 规则**：库没有反射，Compose 的规则由 AGP 自带。
- 换启动器图标时**别把 `mipmap-anydpi-v26` 改成 `mipmap-anydpi`**：AGP 会把自适应图标
  从 APK 里静默丢掉，启动器上会显示成原版那张指南针图（原因写在 `sample/lint.xml` 里）。

## 13. 常见问题

**Q：为什么组件看起来这么「方」？**
锤子风格的列表、标题栏、分组卡片都是直角，只有弹窗、弹层、卡片有小圆角。
需要圆角就把自己的 `SmartisanShapes` 传进 `SmartisanTheme`。

**Q：为什么点击没有涟漪？**
原版的按压反馈是换色 / 位移 / 缩放，所以库内组件都用 `indication = null` 并自绘按压态。
想让自己写的组件也用同一套手感：`Modifier.smartisanClickable { ... }`。

**Q：可以不用 `SmartisanScaffold` 吗？**
可以。它只是「标题栏 + 内容 + 底部栏 + 导航栏留白」的便捷组合，任何组件都能单独使用。

**Q：为什么必须包 `SmartisanTheme`？**
组件从 `CompositionLocal` 读色板、文字样式与形状；不包会抛出明确异常，
而不是静默取一套默认值 —— 这是刻意的，避免出现「颜色看着不太对但没人发现」的页面。

**Q：深色模式为什么是实验性的？**
原版没有深色模式。深色色板与部分素材（约 2.5%）由三个复刻项目新增，
所以深色下的还原度不如浅色，是否启用由你自己评估。

**Q：能和 Material 一起用吗？**
可以，两者互不干扰；只是 smartisanx 组件要包在 `SmartisanTheme` 里，不要放在 `MaterialTheme` 里。

**Q：库里有原版 APK 的素材吗？**
有，而且是刻意保留的：锤子风格是拟物设计，质感来自 NinePatch、位图与 selector。
素材的授权说明见 README 的「资源来源与授权」。

# 快速开始

**中文** · [English](QuickStart.md)

## 环境要求

| 项目 | 要求 |
| --- | --- |
| minSdk | 26（Android 8.0） |
| compileSdk | 37（库依赖 Compose 1.12，消费方需要不低于 37 的 compileSdk） |
| Kotlin | 2.4（需要 Compose 编译器插件；AGP 9 自带 Kotlin 编译，无需 kotlin-android） |
| Compose BOM | 2026.09.00 及以上 |
| AGP | 9.4 及以上（Gradle 9.8 及以上，JDK 17 及以上） |

本库不依赖 Material / Material3，如果你的项目同时使用 Material，两者可以共存，
但请确保 smartisanx 组件包在 `SmartisanTheme` 内，而不是 `MaterialTheme` 内。

## 引入依赖

### 方式一：源码依赖（推荐用于二次开发）

```kotlin
// settings.gradle.kts
include(":library:core")
include(":library:ui")
include(":library:icons")
```

```kotlin
// app/build.gradle.kts
dependencies {
    implementation(project(":library:ui"))
    implementation(project(":library:icons"))
}
```

### 方式二：只依赖某一部分

```kotlin
dependencies {
    implementation(project(":library:core"))  // 只要主题、动画、drawable 绘制
    implementation(project(":library:icons")) // 只要图标
}
```

### 方式三：发布到本地 Maven

```bash
./gradlew publishToMavenLocal
```

```kotlin
dependencies {
    implementation("cc.wuersan008.smartisanx:smartisanx-ui:0.1.0")
    implementation("cc.wuersan008.smartisanx:smartisanx-icons:0.1.0")
}
```

## 第一个界面

```kotlin
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        WindowCompat.setDecorFitsSystemWindows(window, false)
        setContent {
            val controller = rememberSmartisanThemeController()
            SmartisanTheme(controller) {
                SmartisanScaffold(
                    titleBar = {
                        SmartisanTitleBar(
                            title = "我的应用",
                            navigationIcon = SmartisanTitleBarAction(
                                icon = SmartisanXIcons.Back,
                                contentDescription = "返回",
                            ) { /* 返回 */ },
                            actions = listOf(
                                SmartisanTitleBarAction(
                                    icon = SmartisanXIcons.More,
                                    contentDescription = "更多",
                                ) { /* 更多 */ },
                            ),
                        )
                    },
                ) {
                    SmartisanGroup {
                        SmartisanListItem(title = "第一行", summary = "说明文字")
                        SmartisanRowDivider()
                        SmartisanSwitchRow(
                            text = "开关项",
                            checked = true,
                            onCheckedChange = { /* ... */ },
                        )
                    }
                }
            }
        }
    }
}
```

要点：

1. **必须包裹 `SmartisanTheme`**。组件读取 `LocalSmartisanColors`，
   没有主题时会抛出「未找到 SmartisanColors」的明确异常，而不是静默使用错误颜色。
2. **标题栏自带状态栏占位**。`SmartisanTitleBar` 默认 `includeStatusBar = true`，
   会用一个和状态栏等高的占位把内容顶下去；如果你已经在外层处理了 Insets，
   可以把它设为 `false`。
3. **按压反馈不用涟漪**。原版锤子的按压反馈是换色 / 位移 / 缩放，
   所以组件内部都用 `indication = null`，你不需要额外配置。

## 深浅色

**本库默认使用浅色**，与原版 Smartisan OS 一致。

「跟随系统」与「深色」是**实验性**功能，需要开发者显式开启，
并由你自己在产品里向用户说明 —— 原版只有浅色一套设计，深色由三个复刻项目新增，
且原版图形资源里只有约 19% 带夜间变体。
详见[主题与设计变量](主题与设计变量.md#深色模式实验性)。

```kotlin
// 默认：浅色，什么都不用做
SmartisanTheme { /* ... */ }

// 可选：跟随系统 / 深色（实验性）
val controller = rememberSmartisanThemeController(SmartisanColorSchemeMode.System)
SmartisanTheme(controller) { /* ... */ }

// 运行时切换
controller.colorSchemeMode = SmartisanColorSchemeMode.Light // 默认
controller.colorSchemeMode = SmartisanColorSchemeMode.System // 跟随系统（实验性）
controller.colorSchemeMode = SmartisanColorSchemeMode.Dark   // 深色（实验性）
```

也可以只用色板重载，不引入控制器：

```kotlin
SmartisanTheme(colors = lightSmartisanColors()) { /* ... */ }   // 默认
SmartisanTheme(colors = systemSmartisanColors()) { /* ... */ }  // 跟随系统（实验性）
SmartisanTheme(colors = darkSmartisanColors()) { /* ... */ }    // 深色（实验性）
```

同时建议把系统栏图标也一起切换：

```kotlin
val view = LocalView.current
val isLight = LocalSmartisanColors.current.isLight
SideEffect {
    val window = (view.context as Activity).window
    val c = WindowCompat.getInsetsController(window, view)
    c.isAppearanceLightStatusBars = isLight
    c.isAppearanceLightNavigationBars = isLight
}
```

## 自定义主题

所有主题对象都是不可变数据类，可以用 `copy` 派生：

```kotlin
val colors = if (isSystemInDarkTheme()) darkSmartisanColors() else lightSmartisanColors()
SmartisanTheme(
    colors = colors.copy(accent = Color(0xFF3482FF)),
    typography = SmartisanTypography(),
    shapes = SmartisanShapes(),
) {
    // ...
}
```

更细粒度的覆盖（尺寸、动画）可以直接传参，例如：

```kotlin
SmartisanTitleBar(title = "标题", contentHeight = 52.dp)
SmartisanSwitch(checked = on, onCheckedChange = { on = it }, hapticsEnabled = false)
```

## 常见问题

**Q：为什么组件看起来是「方」的？**
锤子风格的列表、标题栏、分组卡片都是直角，只有弹窗、弹层、卡片有小圆角。
如果你需要圆角，把 `SmartisanShapes` 传进主题即可。

**Q：能不能不用 `SmartisanScaffold`？**
可以。`SmartisanScaffold` 只是「标题栏 + 内容 + 底部栏」的便捷组合，
任何组件都可以单独使用。

**Q：库里有原版 APK 的资源吗？**
有，而且是刻意保留的。锤子风格是拟物设计，质感来自 NinePatch、位图与 selector，
所以 `library/ui/src/main/res/` 下直接使用三个复刻项目还原的原版素材（481 个文件）。
矢量图标（`SmartisanXIcons` 等）只用于原版没有对应素材的场景。
素材的授权说明见 README 的「资源来源与授权」。

**Q：为什么不用 Material 的 `Switch` / `Button`？**
锤子的开关、按钮、弹窗都有独立的视觉与手感（可拖动滑块、按下收缩、贴底菜单），
Material 组件无法在不重写绘制的情况下表达，所以这里全部自绘。

# 原版应用组件清单与差距分析

**中文**（本文档只有中文版）

这份文档记录对 [People-11/SmartisanOS_APP_Port](https://github.com/People-11/SmartisanOS_APP_Port)
根目录 12 个原厂 APK 的反编译结果，以及它们与 smartisanx 现有组件的差距。

## 一、反编译方式

| 工具 | 用途 |
| --- | --- |
| apktool 3.0.3 | 解出 `res/`（布局、drawable、动画、values）与 smali |
| jadx 1.5.6 | 解出可读的 Java 源码，用于阅读自定义 View 的绘制与动画 |

注意：部分 APK 依赖 Smartisan 私有 framework（package ID 2），apktool 会提示
`Could not find framework resources`，但 `res/` 仍能完整解出，不影响分析。

## 三、自定义 View 总览

在应用自有包（`com.smartisan.*` 等）下、且实现了 `onDraw` / `onMeasure` / `onLayout` 的类，
共 **213** 个实例、**145** 个唯一类名。

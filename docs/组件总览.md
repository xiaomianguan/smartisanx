### 页面转场（`SmartisanPageTransition` / `SmartisanModalPageTransition`）

```kotlin
@Composable fun SmartisanPageTransition(
    secondary: Boolean, modifier: Modifier = Modifier,
    primary: @Composable () -> Unit, secondaryContent: @Composable () -> Unit,
)

@Composable fun SmartisanModalPageTransition(
    visible: Boolean, modifier: Modifier = Modifier, content: @Composable () -> Unit,
)
```

要点：

- 缓动与时长照抄锤子音乐的 `SmartisanNavigationDuration` 与 `PageStackTransition`：
  打开用 `Smooth` = `(1 - cos(tπ)) / 2`，关闭用 `Decelerate` = `1 - (1-t)²`；
  另外提供原版 XML 里的 `decelerate_cubic`（页面级上推 / 下滑）、
  `decelerate_interpolator`（弹窗缩放淡入）与 `accelerate_interpolator`（底部菜单退出）。
- `SmartisanPageTransition` 还原 `PageStackTransition`：新页面从右侧滑入、旧页面向左让位，
  用 `secondary` 切换主 / 副页；
  `SmartisanModalPageTransition` 还原弹窗式页面的「缩放 + 淡入淡出」进出场。

### 原版控件移植

下面这几个组件直接从原厂 APK 的自定义 View 移植，底图、阴影、动画时长与插值器都照抄原版：

| 组件 | 对应原版类 | 原版出现的 App |
| --- | --- | --- |
| `SmartisanButtonTabGroup` | `smartisanos.widget.ButtonTabGroup` | 日历、短信、音乐、便签、录音机（5 个） |
| `SmartisanNumberPicker` | `SmartisanNumberPicker` / `SmartisanNumberPickerEx` | 时钟、音乐（2 个） |
| `SmartisanPageIndicator` | `smartisanos.app.IndicatorView` | 日历、便签（2 个） |
| `SmartisanProgressIndicator` | `smartisanos.widget.DownloadProgressView` | 日历、邮件（2 个） |
| `SmartisanTips` | `smartisanos.widget.TipsView` | 日历、邮件（2 个） |
| `SmartisanCalculatorButton` | `com.smartisanos.calculator.HammerButton` | 计算器（1 个） |
| `SmartisanSelectionMark` | 原版单选对勾位图（`btn_selected_on_smartisanos_light` / `ringtone_picker_radio_normal`，本库里是同一张 80×80 蓝对勾） | 音乐、时钟（2 个） |
| `SmartisanSpinner` | `smartisanos.widget.SmartisanSpinnerView` | framework 通用下拉选择（设置等；无布局文件，原版用代码拼装） |
| `SmartisanCircleProgress` 家族 | `smartisanos.widget.CircleProgressView` / `CircleProgressPopup` | framework 通用环形进度（下载、暂停、重试、处理中） |
| `SmartisanChips` / `SmartisanChip` | `smartisanos.widget.ChipsView` / `ShadowChipsView` | framework 通用标签（联系人标签、搜索历史、热门词） |
| `SmartisanMarqueeText` | `smartisanos.widget.SmartisanMarqueeView` | framework 通用（标题栏、播放页的主副标题跑马灯） |
| `SmartisanDatePicker` 家族 | `SmartisanDatePicker[Ex]` / `SmartisanDatePicker[Ex]Dialog` / `SmartisanDateTimePicker[Dialog]` | 日历、设置、便签、时钟（含「跳转到日期」） |
| `SmartisanTimePickerDialog` | `smartisanos.widget.SmartisanTimePickerDialog` / `SmartisanTimePickerExDialog` | 时钟、日历 |
| `SmartisanPreviewOptions` / `SmartisanPreviewOptionCell` | `smartisanos.widget.PreviewOptionsCheckView` / `PreviewOptionView` | framework 通用（设置页的两栏预览选项） |
| `SmartisanSmoothSeekBar` | `smartisanos.widget.SmoothSeekBar` | 设置等（framework 通用滑杆） |
| `SmartisanIconSlider` | `smartisanos.widget.SliderWithIcons` | 设置等（带图标的滑杆） |

`SmartisanNumberPicker` 不重复实现滚轮：它复用 `SmartisanWheelPicker`（本次为后者补上了原版的
循环滚动 `wrap`），只额外提供原版的取值区间、格式化与高亮单位后缀语义。

`SmartisanButtonTabGroup` 的分段底图走原版 `selector_small_btn_filter_left / _middle / _right`
与 `selector_small_btn_standard`，相邻分段按原版 `button_tab_group_each_gap = 6dp` 负边距互相压住，
文字阴影取自原版 `color/filter_button_text_shadow_colors`。

`SmartisanCalculatorButton` 的按压位移由原版 selector 自带（按下位图整体内缩约 1dp），
高亮角标按原版 `highlight_padding_right / top`（横竖屏不同）绘制，长按连发沿用原版
`500ms` 起、`150ms` 一次。

`SmartisanPageIndicator`、`SmartisanProgressIndicator` 的部分颜色与半径取自
**Smartisan 私有 framework**（本库拿不到），已改用主题语义色与 2dp 半径代替，可逐个参数覆盖。

### framework 滑杆（`SmartisanSmoothSeekBar` / `SmartisanIconSlider`）

```kotlin
@Composable fun SmartisanSmoothSeekBar(

    value: Float, onValueChange: (Float) -> Unit, modifier: Modifier = Modifier,
    enabled: Boolean = true, steps: Int = 0,
    leading: (@Composable () -> Unit)? = null, trailing: (@Composable () -> Unit)? = null,
)

@Composable fun SmartisanSliderIcon(
    @DrawableRes res: Int, contentDescription: String?, modifier: Modifier = Modifier,
    size: Dp? = null, tint: Color = Color.Unspecified,

```

要点：

- `SmartisanSmoothSeekBar` 对应 framework 的 `smartisanos.widget.SmoothSeekBar`
  （设置里的亮度、音量、字体大小都用它）——**此前本库完全没有滑杆**，这是补上的第一个。
  滑块用原版素材 `progress_control` / 禁用态 `progress_control_disabled`
  （即 `seekbar_scrubber_control_selector` 的两个状态），轨道自绘 2dp。
- `SmartisanIconSlider` 对应 framework 的 `SliderWithIcons` + `slider_with_icons_layout.xml`：
  原版布局只有三条布局规则（左图标 `alignParentLeft` + 居中、右图标 `alignParentRight` + 居中、
  滑杆 `match_parent` 夹在两者之间），**没有任何尺寸常量**，所以也没有对应的 `SmartisanDimens`；
  滑杆本体就是 `SmoothSeekBar` 的 `SeekBarStyle.Thin.LargeThumb.Actived` 样式（最粗的一档滑块）。
- 原版左右图标是 `wrap_content`（按素材固有尺寸画），`SmartisanSliderIcon` 的 `size = null`
  即此行为；要给统一尺寸（比如 26dp）再显式传值。
- 原版「要么两个图标都给、要么两个都不显示」的小脾气没有照搬：Compose 版是两个槽位，给哪个画哪个。
- 标签、滑杆、两端图标竖直居中对齐，已真机逐像素核对（见 `组件核对记录.md`）。
- 图标的禁用态不会跟着变灰：原版只切换滑块的禁用素材，图标由调用方自己决定。
- `SmartisanPreviewOptions` 对应 framework 的 `PreviewOptionsCheckView`（布局
  `preview_options_view_layout.xml`，两栏 `PreviewOptionView` 走
  `preview_single_option_layout.xml`）：顶部标题 13.5sp `#80000000`、左缩进 30dp、
  `maxWidth` 307dp，两栏容器直接用原版 9-patch `preview_options_two`（**中间那条分隔线来自
  9-patch 本身**，不是单独的视图），单元格里预览图上边距 11.5dp、标题 15sp 居中、
  选中角标贴在预览图右上角。
- 点击行为照抄原版 `onClick`：点**已经选中**的那一栏不会再触发回调；禁用时图、标题、角标
  一起走禁用态（角标换成 `preview_picture_selected_disable_solid`，标题转 `#BABABA`）。
  原版的 `setAutoCheck(false)` 在 Compose 版里不需要：选中态由调用方持有，回调里自己决定。

- 来自 framework 的 `smartisanos.widget.MessageField`（布局 `message_field.xml`，是个 `merge`）：
  左图标 36dp（`standard_icon_size`）+ 输入区（底图 `message_field.9.png`，固有高 32dp）+
  发送按钮 36dp（`selector_small_icon_send`，绿色箭头），左右留白都用 `bar_margin_edge` 6dp。
- 三条直接从原版代码里抄来的规则：发送按钮**输入为空即禁用**（走 selector 的 `icon_send_disabled`）；

- 长度上限默认 2000（原版 `integer/message_field_editor_max_length`），超长直接不接收；
  多行时输入区跟着长高（原版 `editorMaxLine`）。
- 底栏上边缘压着 framework 的 `bottom_bar_shadow`
  （`sos_smartisanos_drawable_bottom_bar_shadow`，素材 33px ⇒ 11dp，与 `bottom_bar_shadow_height` 一致）
  + 0.67dp 分隔线，两者都贴栏顶、投影向上平移自身高度（原版 `BarsHelper` 的 `SHADOW_BOTTOM_TYPE`）。
- 差异：原版 `Listener` 的 `beforeTextChanged` / `onTextChanged` 在 Compose 里没有对应物，合并成
  `onValueChange`；文字 / 提示色改用主题 `textPrimary` / `textHint`；导航栏 insets 由调用方处理。

要点：

- `SmartisanSearchBar` 整条高 48dp（原版 `title_bar_height`），编辑区高 32dp、底色用原版
  NinePatch `search_field`（`search_bar_edit_bg_selector`，禁用态 `search_field_disabled`）；
  左图标 `search_bar_left_icon` 24×30dp、清除按钮 `text_clear_btn` 30dp、
  取消 / 筛选按钮 36dp（原版 `standard_icon_size`）；间距依次取原版
  `bar_margin_edge` 6dp、`search_bar_margin_search_view` 6dp、`search_bar_margin_each` 12dp。
- 展开 / 收起动画照抄原版 `SearchBar.startAnimation(boolean)`：编辑区让位展开 300ms、
  收起延迟 100ms 再 200ms；取消按钮位移 `search_bar_anim_distance`（10dp）与透明度
  展开延迟 100ms、收起无延迟，单项都是 200ms，插值器为原版
  `DecelerateInterpolator(1.5f)`；筛选按钮容器与取消按钮相反。
- `SmartisanAutoFitText` 用 `TextMeasurer` 复刻原版 `refitText` 的二分：先量整行宽度，
  放不下就在 `[mFitMinSize(12sp), 当前字号]` 之间二分（收敛精度 0.5px），
  再用同样方式按可用高度压一次。
- `SmartisanJustifyText` 逐行重绘：除最后一行、空行、以换行符结尾的行之外，
  每行按 `(行宽 − 本行自然宽度) / (字符数 − 1)` 摊开字距；段首两空格缩进不被拉伸。
- `SmartisanPasswordField` 的眼睛是原版一次性帧动画 `pwd_eye_open_close_anim`
  （16 帧 × 16ms，取自锤子音乐），总时长按原版公式计算，明文 / 密文在**动画过半**时切换。
- `SmartisanClearableField` 的清除按钮沿用原版 `quick_icon_delete`，且只在
  「文本非空且获得焦点」时出现（原版 `updateDrawableVisibility`）。
- 清除按钮的绘制抽成了唯一实现 `SmartisanClearIcon`，搜索栏与可清空输入框共用，不写两遍。
- 光标条原版是 9-patch `edittext_cursor_bbackground`，Compose 的 `cursorBrush` 只接受
  `Brush`，因此改用主题强调色 `accent`；文字 / 提示色原版取 `editor_text_color`（#cc000000）、
  `editor_hint_text_color`（#26000000），这里改用主题语义色 `textPrimary` / `textHint`。


  自定义 `Layout` 没实现固有测量时一律按「装不下」处理。
- 原版中槽 6 种 `style`（普通文字 / 单选标签页 / 下拉 / 左右翻页 / 跑马灯 / 分隔条）在 Compose 里

- 标题 / 副标题颜色默认用主题 `textSecondary`（≈ 原版 `title_or_btn_text_color` `#99000000`）、
  `textTertiary`，都能分别覆盖；标题 12dp 间距与左右槽竖直居中都已真机逐像素核对。
- 有意不同：原版把右侧最多 10 个按钮用 `-6dp` 右外边距互相压住，本库不做这个「按钮容器」，

全部是 24×24 的 `ImageVector`，用 `SmartisanIcon` 的 `tint` 上色。

这套矢量图标用于**原版没有对应素材**的场景（自绘界面、自定义动作）。
标题栏、开关、弹窗、列表行、表盘等组件默认使用原版位图，见下面的资源索引。

## 资源索引

原版图形资源通过三个对象引用，都在 `cc.wuersan008.smartisanx.ui.asset` 下：

| 对象 | 内容 |
| --- | --- |
| `SmartisanDrawables` | 标题栏、弹窗、菜单、列表行、分组卡片、复选框、评分、开关、字母栏、标签栏、搜索框、分段按钮组、计算器按键、环形下载进度、两栏预览选项（含列表 / 网格图标） |
| `SmartisanClockDrawables` | 大/小机械表盘、指针与投影、刻度数字、闹铃耳朵、响铃卡片时钟、时间滚轮 |
| `SmartisanTimerDrawables` | 计时器卡尺、6.8.0 拉环帧序列、秒表按钮、重复日开关、时钟列表行 |

用法与矢量图标一致，区别是资源自带按下/禁用态：

```kotlin
// 标题栏图标（selector 自带状态）
SmartisanIcon(res = SmartisanDrawables.IconBack, contentDescription = "返回")

// 作为背景（NinePatch 自动拉伸）
Modifier.smartisanDrawableBackground(SmartisanDrawables.GroupRowSingle)

// 表盘这类必须按原尺寸绘制的资源
SmartisanIntrinsicImage(res = SmartisanClockDrawables.Face)
```

`@DrawableRes` 参数都是可替换的，想换成自己的素材直接传别的资源 id 即可。

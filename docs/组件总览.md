## 主题与基础能力

### `cc.wuersan008.smartisanx.core.theme`

| API | 说明 |
| --- | --- |
| `SmartisanTheme(colors, typography, shapes, content)` | 提供主题，**默认浅色** |
| `SmartisanTheme(controller, typography, shapes, content)` | 使用控制器，可运行时切换 |
| `rememberSmartisanThemeController(mode)` | 创建 `ThemeController`，默认 `Light` |
| `ThemeController.colorSchemeMode` | `System` / `Light` / `Dark`（**深色为实验性**，原版没有深色模式） |
| `ThemeController.isDark()` / `colors()` | 当前状态 |
| `lightSmartisanColors()` / `darkSmartisanColors()` | 取默认色板（深色为实验性） |
| `SmartisanColors` | 30 项语义色（见《主题与设计变量》） |
| `SmartisanTypography` | 12 种文字样式 |
| `SmartisanShapes` | 7 种形状 |
| `SmartisanDimens` | 尺寸常量 |

### `cc.wuersan008.smartisanx.core.anim`

| API | 说明 |
| --- | --- |
| `SmartisanMotion.EaseInOut` | 原版余弦缓入缓出 |
| `SmartisanMotion.easeInOut(durationMillis)` | 便捷 `TweenSpec` |
| `SmartisanMotion.PressSpring` / `SettleSpring` / `OffsetSpring` | 弹簧规格 |
| `SmartisanMotion.switchSettleMillis(position, target)` | 开关落位时长 |
| `SmartisanMotionSpec` / `LocalSmartisanMotion` | 整体替换动画规格 |

### `cc.wuersan008.smartisanx.core.interaction`

```kotlin
@Composable fun InteractionSource.collectSmartisanPressedAsState(): State<Boolean>
@Composable fun smartisanClick(onClick: () -> Unit): () -> Unit
@Composable fun smartisanHaptic(): () -> Unit
@Composable fun rememberSmartisanInteractionSource(): MutableInteractionSource
@Composable fun Modifier.smartisanClickable(
    interactionSource: MutableInteractionSource? = null,
    enabled: Boolean = true,
    role: Role? = Role.Button,
    onClickLabel: String? = null,
    onClick: () -> Unit,

```

`collectSmartisanPressedAsState` 保证「同一帧内按下又抬起」的快速点击依然可见，
时长与平台 `ViewConfiguration.getPressedStateDuration()` 一致。

### `cc.wuersan008.smartisanx.core.utils`

```kotlin
@Composable fun rememberSmartisanDrawablePainter(
    @DrawableRes drawableRes: Int,
    enabled: Boolean = true, pressed: Boolean = false, selected: Boolean = false,
    focused: Boolean = false, checked: Boolean = false, activated: Boolean = false,
): Painter

fun Modifier.smartisanPainterBackground(painter: Painter): Modifier
@Composable fun Modifier.smartisanDrawableBackground(...): Modifier

```

用于把应用自己的 selector / NinePatch 画到 Compose 画布上，
状态映射与布局方向处理与原版 View 行为一致。

```kotlin
    onTextLayout: ((TextLayoutResult) -> Unit)? = null,
)

@Composable fun SmartisanPixelText(text: String, size: Dp, ...)

    imageVector: ImageVector, contentDescription: String?,
    modifier: Modifier = Modifier, tint: Color = Color.Unspecified, size: Dp = 24.dp,

@Composable fun SmartisanIconButton(
    onClick: () -> Unit, modifier: Modifier = Modifier, enabled: Boolean = true,
    size: Dp = SmartisanDimens.IconSize, contentDescription: String? = null,
```

`SmartisanText` 有 `String` 与 `AnnotatedString` 两个重载；颜色默认取

`SmartisanPixelText` 还原原版 `TextView` 把 dp 字号取整到物理像素的行为。

## 列表交互（`list`）

```kotlin

    content: @Composable (index: Int, item: T, dragging: Boolean) -> Unit,

@Composable fun SmartisanSwipeToDelete(
    onDelete: () -> Unit, modifier: Modifier = Modifier, enabled: Boolean = true,

    deleteLabel: String = "删除", content: @Composable () -> Unit,
```

- `SmartisanWorldClockCard` 按城市时区计算当地时间与相对本地的时差。

标题栏、开关、弹窗、列表行、表盘等组件默认使用原版位图，见下面的资源索引。

## 资源索引

原版图形资源通过三个对象引用，都在 `cc.wuersan008.smartisanx.ui.asset` 下：

| 对象 | 内容 |
| --- | --- |
| `SmartisanDrawables` | 标题栏、弹窗、菜单、列表行、分组卡片、复选框、评分、开关、字母栏、标签栏、搜索框 |
| `SmartisanClockDrawables` | 大/小机械表盘、指针与投影、刻度数字、闹铃耳朵、响铃卡片时钟、时间滚轮 |
| `SmartisanTimerDrawables` | 计时器卡尺、6.8.0 拉环帧序列、秒表按钮、重复日开关、时钟列表行 |

用法与矢量图标一致，区别是资源自带按下/禁用态：

```kotlin
// 标题栏图标（selector 自带状态）
SmartisanIcon(res = SmartisanDrawables.IconBack, contentDescription = "返回")

// 作为背景（NinePatch 自动拉伸）
Modifier.smartisanDrawableBackground(SmartisanDrawables.GroupRowSingle)

// 表盘这类必须按原尺寸绘制的资源
SmartisanIntrinsicImage(res = SmartisanClockDrawables.Face)
```

`@DrawableRes` 参数都是可替换的，想换成自己的素材直接传别的资源 id 即可。

### 页面转场（`SmartisanPageTransition` / `SmartisanModalPageTransition`）

```kotlin
@Composable fun SmartisanPageTransition(
    secondary: Boolean, modifier: Modifier = Modifier,
    primary: @Composable () -> Unit, secondaryContent: @Composable () -> Unit,
)

@Composable fun SmartisanModalPageTransition(
    visible: Boolean, modifier: Modifier = Modifier, content: @Composable () -> Unit,
)
```

要点：

- 缓动与时长照抄锤子音乐的 `SmartisanNavigationDuration` 与 `PageStackTransition`：
  打开用 `Smooth` = `(1 - cos(tπ)) / 2`，关闭用 `Decelerate` = `1 - (1-t)²`；
  另外提供原版 XML 里的 `decelerate_cubic`（页面级上推 / 下滑）、
  `decelerate_interpolator`（弹窗缩放淡入）与 `accelerate_interpolator`（底部菜单退出）。
- `SmartisanPageTransition` 还原 `PageStackTransition`：新页面从右侧滑入、旧页面向左让位，
  用 `secondary` 切换主 / 副页；
  `SmartisanModalPageTransition` 还原弹窗式页面的「缩放 + 淡入淡出」进出场。

**Smartisan 私有 framework**（本库拿不到），已改用主题语义色与 2dp 半径代替，可逐个参数覆盖。

### 横向进度条（`SmartisanProgressBar`）

```kotlin
@Composable fun SmartisanProgressBar(
    progress: Float, secondaryProgress: Float = 0f,
    state: SmartisanProgressBarState = Normal, thin: Boolean = false, modifier: Modifier = Modifier,
)
```

- 原版没写自定义 View，而是用系统 `ProgressBar` + 一整套 9-patch layer-list
  （`progress_horizontal_drawable_{normal,failed,unfocus}` 与 thin 变体）：轨道
  `progress_track_smartisanos`（固有高 26px = 8.67dp，thin 20px = 6.67dp）、主进度
  `progress_smartisanos`（失败 / 失焦 / 禁用各一张）、次进度 `secondary_progress_smartisanos`；
  主进度层左右各留 1dp（原版 layer-list 写死的 `android:left/right="1dp"`）。
- 素材取自文件管理器（系统 dump 的 `FileManagerSmartisan.apk`），库内按同样的三层结构绘制。

### 弹窗内容版式（`SmartisanDialogAppInfo` / `SmartisanDialogSectionGroup` / `SmartisanDialogSingleChoiceRow`）

```kotlin
@Composable fun SmartisanDialogAppInfo(title, summary: String? = null, modifier, iconRes: Int? = null)
@Composable fun SmartisanDialogSectionGroup(primaryTitle, modifier, subtitle: String? = null, message: String? = null)
@Composable fun SmartisanDialogSingleChoiceRow(title, selected, modifier, summary, onClick, checkRes)
```

- 原版把「应用信息 / 三段说明 / 两行单选」这三种弹窗内容做成了固定的自定义 View + 布局 + 样式，
  各应用弹窗都用它，所以版式完全一致。这里照抄三套：
  应用信息 = 36dp 图标 + 12dp 间距 + 两行（16sp 加粗 `#9a000000` / 12.5sp `#66000000`，都单行省略）；
  三段式 = 主标题 15sp 加粗 + 副标题 12.5sp + 正文 16sp，左右内边距 20dp / 18dp、段间 18dp
  （`dlg_section_vertical_space`）；两行单选行 = 行高 60dp（`dlg_single_choice_height_has_summary`）、
  左 20dp 右 6dp、右侧 `selector_radio_choice` 图标（未选中时不占位）。
- 与原版的差异：单选行的文字颜色原版取系统主题的 `?android:textColorAlertDialogListItem`，
  这里用主题语义色；单选图标默认同一张 `selector_radio_choice`，可换成
  [SmartisanSelectionMark](组件总览.md)。

### 日历（`SmartisanCalendar`）


- 原版是便签 / 提醒里「选提醒时间」的那个月历（素材名都是 `remind_` 开头），
  绘制规则整套照抄：**不在当月的格子是「8% 灰块 + 白色日期数字」**，白字在灰块上等于隐形，
  一屏看过去就是当月那块的形状；**今天那一格写「今天」两个字**（14sp，日期数字是 18sp），
  今天同时是选中日时是蓝药丸、否则是浅灰药丸；选中日单独一张蓝药丸，比格子左右各宽 1dp、
  上下各高 1.4dp；周与周之间的细线来自行底纹素材本身（上下各 1.33dp 的 10% 黑）。
- 尺寸：标题栏 48dp、标题宽 174.6dp（14dp 加粗、`#9a000000`）、左右箭头距边缘 57dp 且 51dp 大、
  下方 1dp 分割线、星期栏 29.3dp（10sp、左右边距 12.3dp）、行高 44dp、
  格子宽 `(网格宽 + 0.8dp) / 7`；网格左右各 12.3dp 的内边距来自外框 9-patch 自带的 padding，
  和星期栏的边距是同一个数，所以两者严格对齐（已用真机截图逐像素核对，见
  [组件核对记录](组件核对记录.md)）。
- 切换月份是 300ms 的整块平移（原版四个 `anim/remind_week_*` 写的是 400ms，但会被
  `SequenceAnimUtils` 改成 300ms），点箭头时选中日期跟着走：回到选中日期所在月就保留原来的日，
  否则落到 1 号（原版 `getMonthCalendarOrOffset`）。
- 与原版的已知差异：`java.time` 取代 `Time` + 儒略日；**竖直方向的「月 ↔ 单周」收起手势没有移植**

  单周视角本来就只由宿主改 adapter 参数打开，本库做成显式参数 `singleWeek`；
  标题用的是系统时区（原版读便签 / 日历的「主页时区」偏好）；死代码（今天的描边高亮
  `drawToday()`、`mAnimateToday`、未被使用的 `remind_today_blue_week_holo_light`）没有移植。

- `SmartisanAutoFitText` 用 `TextMeasurer` 复刻原版 `refitText` 的二分：先量整行宽度，
  放不下就在 `[mFitMinSize(12sp), 当前字号]` 之间二分（收敛精度 0.5px），
  再用同样方式按可用高度压一次。
- `SmartisanJustifyText` 逐行重绘：除最后一行、空行、以换行符结尾的行之外，

- 光标条原版是 9-patch `edittext_cursor_bbackground`，Compose 的 `cursorBrush` 只接受

| `SmartisanOriginalIcons` | 按用途命名的常用图标（`Back` / `More` / `Search` / `Play` / `Settings` …），每个常量指向一张原版 selector，自带按下 / 禁用态 |
| `SmartisanDrawables` | 组件默认使用的原版图形资源（标题栏、弹窗、列表行、分组底图、表盘、标签栏、计算器按键等） |
| `SmartisanIconSet` | 从原厂 APK 提取的 3580 个原版图标总表，分 8 组（标题栏 72 / 标签栏 51 / 列表 158 / 选择 10 / 媒体 25 / 时钟 30 / 编辑 30 / 其他 3204），示例应用的「原版图标」页逐组展示 |

用法见下面的资源索引；需要自定义矢量图标时，`SmartisanIcon(imageVector = ...)` 与
`SmartisanTitleBarAction(imageVector, ...)` 也接受任意 `ImageVector`。

## 资源索引

原版图形资源通过三个对象引用，都在 `cc.wuersan008.smartisanx.ui.asset` 下：

| 对象 | 内容 |
| --- | --- |
| `SmartisanDrawables` | 标题栏、弹窗、菜单、列表行、分组卡片、复选框、评分、开关、字母栏、标签栏、搜索框、分段按钮组、计算器按键、环形下载进度、两栏预览选项（含列表 / 网格图标） |
| `SmartisanClockDrawables` | 大/小机械表盘、指针与投影、刻度数字、闹铃耳朵、响铃卡片时钟、时间滚轮 |
| `SmartisanTimerDrawables` | 计时器卡尺、6.8.0 拉环帧序列、秒表按钮、重复日开关、时钟列表行 |

用法与矢量图标一致，区别是资源自带按下/禁用态：

```kotlin
// 标题栏图标（selector 自带状态）
SmartisanIcon(res = SmartisanDrawables.IconBack, contentDescription = "返回")

// 作为背景（NinePatch 自动拉伸）
Modifier.smartisanDrawableBackground(SmartisanDrawables.GroupRowSingle)

// 表盘这类必须按原尺寸绘制的资源
SmartisanIntrinsicImage(res = SmartisanClockDrawables.Face)
```

`@DrawableRes` 参数都是可替换的，想换成自己的素材直接传别的资源 id 即可。

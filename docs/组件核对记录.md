# 组件核对记录

**中文** · [English](ComponentVerification.md)

这份文档记录把 smartisanx 的组件逐个对照原始实现核对的结果：
对照对象优先是三个复刻项目（同为 Compose，可直接比对），
其次是从原厂 APK 反编译出来的自定义 View 与资源。

核对方法：对每个组件找出原始实现，逐项比对**尺寸常量、几何、时长、缓动、手势物理与所用资源**，
而不是只看「像不像」。

## 一、核对结论总览

| 组件 | 对照来源 | 结论 |
| --- | --- | --- |
| `SmartisanTitleBar` | 音乐 `SmartisanTitleBar` + 天气 `WeatherTitleBar` | ✅ 图标 36dp、左右留白 6dp、标题 20sp、投影 14dp、按压 1.33 倍全部一致；高度取 48dp（见下） |
| `SmartisanSwitch` | 音乐 Compose 开关 + 时钟 `SmartisanSwitchView` / `SmartisanSwitchExView` | ✅ 落位公式一致、投影 200ms 余弦淡出一致、可拖动与触感一致 |
| `SmartisanSwipeToDelete` | 时钟 `SmartisanSwipeDeleteMotion` | ✅ 65dp 直接位移、1/5 阻尼、360dp 上限一致；阈值已修正为原版 50dp |
| `SmartisanAnalogClock` | 时钟 `AnalogClockHandsView` | ✅ 基准画布 360×400、指针锚点 6.9/8 与 6.5/8、数字 108dp / 84.6dp 全部一致 |
| `SmartisanCompactClock` | 时钟 `SmallWorldClockView` | ✅ 锚点 6.7/8、7.2/8、6.5/8 与 4px 投影偏移一致；18:00–06:00 切夜间底图一致 |
| `SmartisanRulerPicker` | 时钟 `TimerRulerView` | ✅ 一分钟 = 一张刻度位图宽度的平铺方式一致，卡尺三层底图一致 |
| `SmartisanModal` / `SmartisanDialog` | 音乐 `SmartisanModal` + 时钟 `SmartisanModalDialog` | ✅ 308dp 宽、10dp 圆角、48dp 标题栏与按钮、1px 分隔线、遮罩 0.54 全部一致 |
| `SmartisanMenuDialog` | 时钟 `SmartisanMenuDialog` | ✅ 贴底、左右 18dp、按钮上下 18/24dp、按钮高 48dp 一致 |
| `SmartisanBottomSheet` | 音乐 `SmartisanAnimatedSheet` | ✅ 底部滑入、进入 300ms / 退出 250ms 一致 |
| `SmartisanLetterIndexBar` | 音乐字母快捷栏 + 时钟 `QuickBarEx` | ✅ 按住连续选择、放大气泡一致 |

## 二、已知差异（有意为之）

这些地方本库与原版**故意不同**，都已在对应组件的 KDoc 里注明：

| 项目 | 原版 | 本库 | 原因 |
| --- | --- | --- | --- |
| 标题栏高度 | 音乐 50dp / 天气与时钟 48dp | 48dp | 三个应用本身就不一致，取多数；需要 50dp 时传 `contentHeight = 50.dp` |
| 深色模式 | 原版没有 | 实验性，默认关闭 | 由复刻项目新增，且原版素材只有约 19% 带夜间变体 |
| 文字 / 提示色 | `editor_text_color` 等取自 framework | 主题语义色 | 这些资源只在 Smartisan framework 里，拿不到 |
| 光标条 | nine-patch `edittext_cursor_bbackground` | 主题 `accent` | Compose 的 `cursorBrush` 只接受 `Brush` |
| 清除按钮显隐 | `setVisibility` 瞬时切换 | 默认 200ms 淡入淡出 | 可传 `animateClearIcon = false` 完全对齐原版 |
| 滚动条 | 系统默认滚动条 | 自绘细滚动条 | 原版没有对应位图 |
| 文字标签栏 | 原版没有文字标签栏 | 自绘 | 原版标签切换都是图标式 |

## 三、资源与字体的核对

- **图形资源**：全部来自原厂 APK 的 `res/drawable*` / `mipmap*`，按内容去重，
  保留原始文件名与夜间 / 多密度限定符目录。
- **字体**：正文用 Smartisan OS 系统字体 `Smartisan Compact CNS`，
  取自坚果 R2 官方 ROM 转储的 `system/system/fonts/`；
  字体内嵌名称与字重已通过解析 OTF `name` 表核对（family = `Smartisan Compact CNS`）。
- **图标**：把 selector 链解析到最底层位图后分类，
  排除了 2195 个 nine-patch 按钮底图与 1647 张大图，只保留真图标。

## 四、尚未逐项核对的部分

诚实说明：以下内容**没有**做到逐像素级核对，因为这里没有设备可以运行：

- 实际渲染观感（颜色、阴影浓淡、字号在真机上的表现）；
- 动画的流畅度与手感（时长与缓动数值已核对，但观感未验证）；
- 手势的边界情况（快速拖动、多点触控、边界回弹的具体手感）；
- 深色模式下各资源的实际表现。

需要的话，可以针对具体某个组件把它的绘制代码与原版 `onDraw` 逐行比对。

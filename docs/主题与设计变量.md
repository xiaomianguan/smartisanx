# 主题与设计变量

**中文** · [English](Theme.md)

## 主题入口

```kotlin
@Composable
fun SmartisanTheme(
    colors: SmartisanColors = lightSmartisanColors(),   // 默认浅色
    typography: SmartisanTypography = SmartisanTypography(),
    shapes: SmartisanShapes = SmartisanShapes(),
    content: @Composable () -> Unit,
)

@Composable
fun SmartisanTheme(
    controller: ThemeController,
    typography: SmartisanTypography = SmartisanTypography(),
    shapes: SmartisanShapes = SmartisanShapes(),
    content: @Composable () -> Unit,
)
```

主题通过四个 `CompositionLocal` 下发：

| CompositionLocal | 内容 |
| --- | --- |
| `LocalSmartisanColors` | 语义色板 |
| `LocalSmartisanTypography` | 文字样式 |
| `LocalSmartisanShapes` | 形状 |
| `LocalSmartisanContentColor` | 内容默认色（由 `SmartisanSurface` 写入） |

另有 `LocalSmartisanThemeController` 暴露当前控制器（可为空）。

## 深色模式（实验性）

> **原版 Smartisan OS 没有深色模式，因此本库默认使用浅色，深色需要显式开启。**

`SmartisanTheme` 与 `rememberSmartisanThemeController` 的默认值都是
`SmartisanColorSchemeMode.Light`；要跟随系统或强制深色，必须由开发者显式传入：

```kotlin
// 默认：浅色
SmartisanTheme { /* ... */ }

// 可选：跟随系统 / 深色（实验性）
val controller = rememberSmartisanThemeController(SmartisanColorSchemeMode.System)
SmartisanTheme(controller) { /* ... */ }

// 也可以只用色板重载
SmartisanTheme(colors = systemSmartisanColors()) { /* ... */ }
```

深色方案来自三个复刻项目的新增设计：炭灰色板最早在锤子天气复刻里校准，
锤子音乐复刻沿用同一套，本库把它整理成 `darkSmartisanColors()`。

因此深色属于**实验性**特性，有两点已知限制：

| 限制 | 说明 |
| --- | --- |
| 夜间素材不全 | 7919 个原版 drawable 中只有 195 个（约 2.5%）带夜间变体，其余 7724 个只有浅色版本，深色下会继续显示浅色素材 |
| 颜色状态列表无夜间版本 | `res/color/` 下没有任何夜间变体，弹窗、菜单等文字色沿用浅色取值；本库额外为锤子时钟的弹窗与菜单补了一套夜间颜色 |

`SmartisanTheme` 会把「当前是否深色」写进 `LocalSmartisanDarkOverride`，
组件据此按应用主题（而不是系统 uiMode）解析 `drawable-night` / `values-night`，
这样应用内切换深浅色时资源才会跟着切。

如果你需要与浅色同等的还原度，请以浅色为准。

### 页面与弹层转场

转场参数取自原版 APK 里的 `anim/` 资源与复刻项目的实现，不是随手定的：

| 场景 | 原版依据 | 行为 |
| --- | --- | --- |
| 常规页面（返回箭头退出） | 锤子音乐 `PageStackTransition` | 新页面从**右侧滑入**，旧页面向左让位；300ms，进入 `Smooth` = `(1-cos(tπ))/2`，退出 `Decelerate` = `1-(1-t)²` |
| 模态页面（× 关闭） | 锤子天气 `pop_up_in` / `slide_down_out` | **从底部滑入**；进入 `translateY` 100%→0，退出 0→109%，都是 300ms、`decelerate_cubic`；底下的页面不动（原版 `fake_anim`） |
| 居中弹窗 | 锤子时钟 `smartisan_modal_enter/exit` | 缩放 0.9→1.0 同时淡入；进入 300ms、退出 250ms，`decelerate` / `accelerate` |
| 底部菜单弹窗 | 锤子时钟 `smartisan_menu_enter/exit` | `translateY` 100%→0 进入 300ms、退出 250ms |

用法：

```kotlin
// 常规页面：右侧滑入
SmartisanPageTransition(
    secondary = detail != null,
    primary = { Home(onOpen = { detail = it }) },
) {
    Detail(onBack = { detail = null })
}

// 模态页面：底部滑入
SmartisanModalPageTransition(visible = sheetOpen) {
    SheetContent()
}
```

缓动常量放在 `cc.wuersan008.smartisanx.ui.anim`：
`SmartisanNavigationOpenEasing`、`SmartisanNavigationCloseEasing`、
`SmartisanDecelerateCubic`、`SmartisanDecelerate`、`SmartisanAccelerate`，
时长常量是 `SmartisanNavigationDuration`（300ms）。

## 字体

**默认使用锤子原厂字体。**

| 用途 | 字体 | 来源 |
| --- | --- | --- |
| 正文 | `Smartisan Compact CNS`（方正出品，四档字重） | 坚果 R2 官方 ROM 转储 `system/system/fonts/Smartisan_Compact-*.otf` |
| 机械数字（时钟、计时器） | `SmartisanClock` 三档字重 | `smartisanos_11.apk` 的 `assets/SmartisanClock*.ttf/otf` |

字体文件放在 `library/core/src/main/res/font/`，通过 `SmartisanFonts.Original` 接入，
由 `SmartisanTheme` 自动套用到全部文字样式（`withFonts()`）。

### 关于 smartisan-compact-cns

原版 Smartisan OS 的界面字体就是系统字体 **`Smartisan Compact CNS`**
（文件名为 `Smartisan_Compact-*.otf`，字体内嵌名称为 `Smartisan Compact CNS`，方正出品）。
它位于 ROM 的 `/system/fonts/`，不在 APK 里 —— 本库的字体取自坚果 R2 的官方 ROM 转储：

<https://dumps.tadiphone.dev/dumps/smartisan/darwin> → `system/system/fonts/`

ROM 里共有六档字重，本库接入了其中四档（其余两档没有被引用到）：

| Compose 字重 | ROM 文件 | 是否接入 |
| --- | --- | --- |
| `Thin` (100) | `Smartisan_Compact-Thin.otf` | 未接入（未引用） |
| `Light` (300) | `Smartisan_Compact-Light.otf` | 已接入 |
| `Normal` (400) | `Smartisan_Compact-Regular.otf` | 已接入 |
| `Medium` (500) | `Smartisan_Compact-Medium.otf` | 已接入 |
| `Bold` (700) | `Smartisan_Compact-Bold.otf` | 已接入 |
| `Heavy` (900) | `Smartisan_Compact-Heavy.otf` | 未接入（未引用） |

需要 Thin / Heavy 时，把对应文件放进 `library/core/src/main/res/font/`，
再在 `SmartisanFonts.Original` 里补一行 `Font(...)` 即可。

### 换字体

三种方式，任选其一。

**跟随系统默认字体**（不加载任何字体文件）：

```kotlin
SmartisanTheme(fonts = SmartisanFonts.SystemDefault) { /* ... */ }
```

**用自己的字体**：

```kotlin
val myFont = FontFamily(Font(R.font.my_font))
SmartisanTheme(fonts = SmartisanFonts.custom(myFont)) { /* ... */ }
```

**只用自绘字体做机械数字**：

```kotlin
SmartisanTheme(
    fonts = SmartisanFonts.custom(text = null, numerals = myClockFont),
) { /* ... */ }
```

### 字体与文字样式的关系

`SmartisanTypography` 里的每个样式都带 `fontFamily`；`SmartisanTheme` 会用
`withFonts()` 把所选字体套到全部样式上，其中 `numeric` 与 `displayNumeric`
用机械数字字体，其余用正文字体。想逐个样式覆盖，直接传自己的 `SmartisanTypography` 即可。

## 页面底纹与卡片投影


锤子应用的页面不是纯色底：**整页是一张细竖条纹布纹**，内容放在**带向外投影的卡片**里。
这两件事都不是靠 Compose 的 `elevation` 或纯色实现的，而是靠原版位图。

### 底纹

`common_bg` 是一张 270×270 的浅灰细竖条纹图。原版通过两张包装 drawable 平铺它：

| 资源 | 内容 | 用在哪 |
| --- | --- | --- |
| `list_bg` | `<bitmap src="@drawable/common_bg" tileMode="repeat"/>` | 锤子天气的页面底、夜间窗口背景 |
| `account_background` | 同上 | 锤子音乐的外壳、设置页、播放队列 |

本库里对应 `SmartisanDrawables.PageBackground`（= `list_bg`）。
`SmartisanScaffold` 默认就用它平铺满屏；传 `backgroundRes = null` 退回主题纯色。

### 卡片投影

卡片是**两层**：

| 层 | 资源 | 作用 |
| --- | --- | --- |
| 内容底图 | `group_list_item_bg_top` / `_mid` / `_bottom` / `_single` | 行自身的圆角、描边与按压态 |
| 投影 | `list_content_item_top_shadow` / `_middle_shadow` / `_bottom_shadow` / `_single_shadow` | 9-patch，按自身 padding 向四周扩张后绘制 |

绘制顺序是先投影、后内容；投影按 9-patch 的 padding **向外扩张**，
所以投影落在控件边界**之外**（这正是原版 `ShadowDrawable` 的做法）。

对应 API：

```kotlin
// 低层：自己指定底图与投影
Modifier.smartisanShadowBackground(backgroundRes, shadowRes)

// 高层：按位置自动配对
SmartisanGroupItem(SmartisanGroupRowPosition.Top, "第一行")
SmartisanCard(backgroundRes = ..., shadowRes = ...) { /* ... */ }
```

### 留白

因为投影画在边界之外，行与分组必须留出边距，否则投影会被裁掉：

| 名称 | 原版资源 | 值 | 用法 |
| --- | --- | --- | --- |
| `SmartisanDimens.ListItemHorizontalMargin` | `list_item_left_right_margin` | 12dp | 分组左右外边距，`SmartisanGroup` 默认已用 |
| `SmartisanDimens.ListItemVerticalGap` | `list_item_vertical_gap` | 14dp | **分组之间**的空白 View，用 `SmartisanListVerticalGap()` 显式插入 |

原版的纵向间距是一个插在两个分组之间的空白 View（`group_list_item_vertical_gap_layout`），
不是分组自己的内边距 —— 两张卡片的投影（9-patch 上下各向外扩 14dp）正好落在这段留白里互相重叠。
所以 `SmartisanGroup` 自己不占纵向间距、只有左右外边距：相邻的两个分组之间请显式插一个
`SmartisanListVerticalGap`，分组标题前后则不用（标题自带留白）。

### 行高

| 名称 | 原版资源 | 值 |
| --- | --- | --- |
| `SmartisanDimens.ListItemHeight` | `listview_item_height` | 60dp |
| `SmartisanDimens.ListItemMinHeight` | `list_item_min_height` | 60dp |

原版 `list_content_item_layout.xml` 是一个 `RelativeLayout`，根节点写着
`android:minHeight="@dimen/list_item_min_height"`，而 `list_item_min_height` 就是 **60dp**
（与 `listview_item_height` 同值）。所以「单行文字的行也是 60dp」，只有内容更多
（副标题折成两行、标题两行）时行才变高。`SmartisanListItem` 的默认 `minHeight` 取
`ListItemMinHeight`，因此所有行都落在这个 60dp 网格上。

## 覆盖与扩展

- 只改颜色：`SmartisanTheme(colors = lightSmartisanColors().copy(accent = ...))`
- 只改形状：`SmartisanTheme(shapes = SmartisanShapes(medium = RoundedCornerShape(12.dp)))`
- 单个组件覆盖：几乎所有组件都提供 `color` / `size` / `shape` / `contentHeight` 之类的显式参数，
  优先使用它们，而不是全局改主题。

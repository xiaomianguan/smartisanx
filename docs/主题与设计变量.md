# 主题与设计变量

**中文** · [English](Theme.md)

## 主题入口

```kotlin
@Composable
fun SmartisanTheme(
    colors: SmartisanColors = lightSmartisanColors(),   // 默认浅色
    typography: SmartisanTypography = SmartisanTypography(),
    shapes: SmartisanShapes = SmartisanShapes(),
    content: @Composable () -> Unit,
)

@Composable
fun SmartisanTheme(
    controller: ThemeController,
    typography: SmartisanTypography = SmartisanTypography(),
    shapes: SmartisanShapes = SmartisanShapes(),
    content: @Composable () -> Unit,
)
```

主题通过四个 `CompositionLocal` 下发：

| CompositionLocal | 内容 |
| --- | --- |
| `LocalSmartisanColors` | 语义色板 |
| `LocalSmartisanTypography` | 文字样式 |
| `LocalSmartisanShapes` | 形状 |
| `LocalSmartisanContentColor` | 内容默认色（由 `SmartisanSurface` 写入） |

另有 `LocalSmartisanThemeController` 暴露当前控制器（可为空）。

## 深色模式（实验性）

> **原版 Smartisan OS 没有深色模式，因此本库默认使用浅色，深色需要显式开启。**

`SmartisanTheme` 与 `rememberSmartisanThemeController` 的默认值都是
`SmartisanColorSchemeMode.Light`；要跟随系统或强制深色，必须由开发者显式传入：

```kotlin
// 默认：浅色
SmartisanTheme { /* ... */ }

// 可选：跟随系统 / 深色（实验性）
val controller = rememberSmartisanThemeController(SmartisanColorSchemeMode.System)
SmartisanTheme(controller) { /* ... */ }

// 也可以只用色板重载
SmartisanTheme(colors = systemSmartisanColors()) { /* ... */ }
```

深色方案来自三个复刻项目的新增设计：炭灰色板最早在锤子天气复刻里校准，
锤子音乐复刻沿用同一套，本库把它整理成 `darkSmartisanColors()`。

因此深色属于**实验性**特性，有两点已知限制：

| 限制 | 说明 |
| --- | --- |
| 夜间素材不全 | 1008 个原版 drawable 中只有 194 个（约 19%）带夜间变体，其余 814 个只有浅色版本，深色下会继续显示浅色素材 |
| 颜色状态列表无夜间版本 | `res/color/` 下没有任何夜间变体，弹窗、菜单等文字色沿用浅色取值；本库额外为锤子时钟的弹窗与菜单补了一套夜间颜色 |

`SmartisanTheme` 会把「当前是否深色」写进 `LocalSmartisanDarkOverride`，
组件据此按应用主题（而不是系统 uiMode）解析 `drawable-night` / `values-night`，
这样应用内切换深浅色时资源才会跟着切。

如果你需要与浅色同等的还原度，请以浅色为准。

## 字体

**默认使用锤子原厂字体。**

| 用途 | 字体 | 来源 |
| --- | --- | --- |
| 正文 | `FZCCHK`（方正粗黑宋简体） | `smartisanos_11.apk` 的 `assets/FZCCHK.TTF` |
| 机械数字（时钟、计时器） | `SmartisanClock` 三档字重 | 同上，`assets/SmartisanClock*.ttf/otf` |

字体文件放在 `library/core/src/main/res/font/`，通过 `SmartisanFonts.Original` 接入，
由 `SmartisanTheme` 自动套用到全部文字样式（`withFonts()`）。

### 关于 smartisan-compact-cns

原版 Smartisan OS 的界面字体是系统字体 **smartisan-compact-cns**，它位于 ROM 的
`/system/fonts/`，**不在任何一个 APK 里**。本项目能拿到的原厂资源
（12 个 APK、`Tool/framework-res.apk`、`Tool/smartisanos_11.apk`）都不包含它，
因此默认字体改用同一套系统里能拿到的锤子字体。

要换成真正的 `smartisan-compact-cns`：

1. 把字体文件放到 `library/core/src/main/res/font/smartisan_compact_cns.ttf`
   （文件名必须全小写、下划线）；
2. 在 `SmartisanFonts.Original` 里把 `R.font.fzcchk` 换成 `R.font.smartisan_compact_cns`。

### 换字体

三种方式，任选其一。

**跟随系统默认字体**（不加载任何字体文件）：

```kotlin
SmartisanTheme(fonts = SmartisanFonts.SystemDefault) { /* ... */ }
```

**用自己的字体**：

```kotlin
val myFont = FontFamily(Font(R.font.my_font))
SmartisanTheme(fonts = SmartisanFonts.custom(myFont)) { /* ... */ }
```

**只用自绘字体做机械数字**：

```kotlin
SmartisanTheme(
    fonts = SmartisanFonts.custom(text = null, numerals = myClockFont),
) { /* ... */ }
```

### 字体与文字样式的关系

`SmartisanTypography` 里的每个样式都带 `fontFamily`；`SmartisanTheme` 会用
`withFonts()` 把所选字体套到全部样式上，其中 `numeric` 与 `displayNumeric`
用机械数字字体，其余用正文字体。想逐个样式覆盖，直接传自己的 `SmartisanTypography` 即可。

## 页面底纹与卡片投影


锤子应用的页面不是纯色底：**整页是一张细竖条纹布纹**，内容放在**带向外投影的卡片**里。
这两件事都不是靠 Compose 的 `elevation` 或纯色实现的，而是靠原版位图。

### 底纹

`common_bg` 是一张 270×270 的浅灰细竖条纹图。原版通过两张包装 drawable 平铺它：

| 资源 | 内容 | 用在哪 |
| --- | --- | --- |
| `list_bg` | `<bitmap src="@drawable/common_bg" tileMode="repeat"/>` | 锤子天气的页面底、夜间窗口背景 |
| `account_background` | 同上 | 锤子音乐的外壳、设置页、播放队列 |

本库里对应 `SmartisanDrawables.PageBackground`（= `list_bg`）。
`SmartisanScaffold` 默认就用它平铺满屏；传 `backgroundRes = null` 退回主题纯色。

### 卡片投影

卡片是**两层**：

| 层 | 资源 | 作用 |
| --- | --- | --- |
| 内容底图 | `group_list_item_bg_top` / `_mid` / `_bottom` / `_single` | 行自身的圆角、描边与按压态 |
| 投影 | `list_content_item_top_shadow` / `_middle_shadow` / `_bottom_shadow` / `_single_shadow` | 9-patch，按自身 padding 向四周扩张后绘制 |

绘制顺序是先投影、后内容；投影按 9-patch 的 padding **向外扩张**，
所以投影落在控件边界**之外**（这正是原版 `ShadowDrawable` 的做法）。

对应 API：

```kotlin
// 低层：自己指定底图与投影
Modifier.smartisanShadowBackground(backgroundRes, shadowRes)

// 高层：按位置自动配对
SmartisanGroupItem(SmartisanGroupRowPosition.Top, "第一行")
SmartisanCard(backgroundRes = ..., shadowRes = ...) { /* ... */ }
```

### 留白

因为投影画在边界之外，行与分组必须留出边距，否则投影会被裁掉：

| 名称 | 原版资源 | 值 |
| --- | --- | --- |
| `SmartisanDimens.ListItemHorizontalMargin` | `list_item_left_right_margin` | 12dp |
| `SmartisanDimens.ListItemVerticalGap` | `list_item_vertical_gap` | 14dp |

`SmartisanGroup` 已经默认用这两个值。

## 动画规格

`SmartisanMotion`：

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `EaseInOut` | `cos((t + 1) * π) / 2 + 0.5` | 原版默认插值器 |
| `DurationShort` | 200ms | 按压、标签切换 |
| `DurationMedium` | 300ms | 页面元素进出 |
| `DurationLong` | 400ms | 整页展开收起 |
| `PressedScale` | 1.33f | 标题栏图标按压放大 |
| `PressSpring` | 阻尼 0.55 / 刚度 800 | 按压回弹 |
| `SettleSpring` | 低回弹 | 列表让位、拖拽落位 |
| `switchSettleMillis` | 按位移换算 | 开关滑块落位时长 |

## 覆盖与扩展

- 只改颜色：`SmartisanTheme(colors = lightSmartisanColors().copy(accent = ...))`
- 只改形状：`SmartisanTheme(shapes = SmartisanShapes(medium = RoundedCornerShape(12.dp)))`
- 单个组件覆盖：几乎所有组件都提供 `color` / `size` / `shape` / `contentHeight` 之类的显式参数，
  优先使用它们，而不是全局改主题。

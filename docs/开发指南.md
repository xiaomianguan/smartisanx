# 开发指南

**中文** · [English](DevelopmentGuide.md)

这份文档面向「用 smartisanx 写一个完整应用」的人（也包括接手这个仓库的 AI 助手）。
它回答三类问题：**页面怎么拼**、**常见页面怎么做**、**改库的时候守什么规矩**。
单个组件的参数表在[组件总览](组件总览.md)，主题的完整取值在[主题与设计变量](主题与设计变量.md)。

## 1. 五分钟建立心智模型

原版锤子应用的页面只有四层：

```
页面 = 条纹底纹（common_bg 平铺） + 标题栏（含栏外投影） + 内容 + 系统栏留白
内容 = 分组标题 + 一列卡片
卡片 = 每一行自己的 NinePatch（白底 + 10dp 圆角 + 1px 描边 + 向外 14dp 投影）
分组 = 透明容器（只管左右各 12dp 外边距）
```

由此推出四条「不能违反」的规则：

| 规则 | 为什么 | 违反了会怎样 |
| --- | --- | --- |
| 组件必须包在 `SmartisanTheme` 里 | 颜色 / 文字样式 / 形状来自 `CompositionLocal` | 抛「未找到 SmartisanColors」异常 |
| 分组里的行必须传 `position` | 卡片被拆成上 / 中 / 下 / 单张四段底图 | 圆角跑到中间行上、卡片接缝错位 |
| 相邻分组之间插 `SmartisanListVerticalGap()` | 卡片投影画在边界**之外**，需要 14dp 落下来 | 两张卡片贴在一起、投影互相压住 |
| 内容不要直接放在底纹上 | 原版所有内容都长在白色卡片里 | 一眼看出「不像锤子」—— 这正是示例应用最早的问题 |

术语（本文与组件总览统一用这几个词）：

- **行（row）**：列表里的一条，例如「允许通知」「第一首歌」；
- **分组（group）**：把若干行拼成一张卡片的透明容器；
- **卡片（card）**：白底 + 圆角 + 向外投影的那一块，由行或分组自己画；
- **页面底纹**：整页那张 270×270 的细竖条纹布纹（`common_bg`）。

## 2. 一个页面的标准结构

```kotlin
@Composable
fun SettingsScreen(onBack: () -> Unit) {
    SmartisanScaffold(
        titleBar = {
            SmartisanTitleBar(
                title = "设置",
                navigationIcon = SmartisanTitleBarAction(SmartisanOriginalIcons.Back, "返回", onBack),
            )
        },
    ) {
        Column(Modifier.fillMaxWidth().verticalScroll(rememberScrollState())) {
            // 页面第一条留白：对应原版 group_list_item_vertical_gap_layout
            SmartisanListVerticalGap()

            SmartisanSectionTitle("通知")
            SmartisanGroup {
                SmartisanGroupItem(SmartisanGroupRowPosition.Top, "允许通知")
                SmartisanGroupItem(SmartisanGroupRowPosition.Middle, "锁屏显示", showDivider = true)
                SmartisanGroupItem(SmartisanGroupRowPosition.Bottom, "通知铃声")
            }

            // 两个分组之间：同样是一条 14dp 留白
            SmartisanListVerticalGap()

            SmartisanSectionTitle("关于")
            SmartisanGroup {
                SmartisanGroupItem(
                    position = SmartisanGroupRowPosition.Single,
                    title = "版本",
                    summary = "1.0.0",
                    trailing = { SmartisanListRowArrow() },
                    onClick = { /* ... */ },
                )
            }

            // 页面最后一条留白：卡片投影不要贴到系统栏
            SmartisanListVerticalGap()
        }
    }
}
```

要点：

1. `SmartisanScaffold` 已经给了底纹、标题栏（含状态栏占位与栏外投影）和导航栏留白，
   内容区只管自己滚不滚；
2. **首尾都要留白**：原版用 `settings_item_top_bottom_margin` 给列表上下各留 14dp；
3. 分组标题前后**不用**留白，`SmartisanSectionTitle` 自带（上 19.5dp / 下 5.5dp）；
4. 行与行之间的分隔线用 `showDivider = true`，它自带 30dp 起始缩进
   （`SmartisanDimens.RowContentStart`），与文字左沿对齐。

> 把这段当模板用：示例应用的 13 个组件页与 13 张整页布局都是这个结构。

## 3. 行与分组：完整规则

### 3.1 三个行组件怎么选

| 组件 | 底图 | 文字版式 | 什么时候用 |
| --- | --- | --- | --- |
| `SmartisanGroupItem(position = ...)` | 按位置取分组卡片的一段 | 15sp 标题 + 12.5sp 说明 | 分组里的一行（最常用） |
| `SmartisanListItem` | 整张单行卡片 | 同上 | 单独一行，不在分组里 |
| `SmartisanListRow(lines = ...)` | 整张单行卡片 | 17sp / 16sp 标题 + 二 / 三行 | 需要 framework 原始字号，或要三行文字 |

三者的**槽位几何完全一致**（左槽固定 60dp、右槽 6dp 边距、中间 18dp 弹性间距），
所以同一个页面里混用不会错位：24dp 与 36dp 的图标后面，文字都从距屏幕左 72dp 处开始。

### 3.2 position 怎么给

| 位置 | 什么时候 | 底图 |
| --- | --- | --- |
| `Top` | 分组第一行（且不止一行） | 上段（上方带圆角） |
| `Middle` | 中间行 | 中段（无圆角） |
| `Bottom` | 分组最后一行 | 下段（下方带圆角） |
| `Single` | 分组里只有一行 | 整张（四角圆角） |

**动态列表**按索引算：

```kotlin
SmartisanGroup {
    items.forEachIndexed { index, item ->
        SmartisanGroupItem(
            position = when (index) {
                0 -> SmartisanGroupRowPosition.Top
                items.lastIndex -> SmartisanGroupRowPosition.Bottom
                else -> SmartisanGroupRowPosition.Middle
            },
            title = item.title,
            showDivider = index != items.lastIndex,
        )
    }
}
```

### 3.3 分组里放的不是列表行

控件排排站、自定义内容这类「自己不画卡片」的东西，交给分组统一画：

```kotlin
SmartisanGroup(position = SmartisanGroupRowPosition.Single) {
    Column(Modifier.fillMaxWidth().padding(horizontal = 18.dp, vertical = 14.dp)) {
        SmartisanText("一整块自定义内容", style = typography.sectionTitle)
        SmartisanText("它自己不画卡片，由分组补上底图与投影", style = typography.caption)
    }
}
```

> 传了 `position` 之后分组的 `color` / `shape` 就失效了 —— 底图与投影都来自原版素材。

### 3.4 分隔线

- 行自带：`showDivider = true`（推荐，缩进与文字左沿对齐）；
- 手动：`SmartisanRowDivider()`（行与行之间）、`SmartisanGroupDivider()`（分组内部更淡的一条）；
- 两者都能用 `startIndent` 调缩进，传 `0.dp` 就是通栏。

### 3.5 三种最常见的错误

| 症状 | 原因 | 修法 |
| --- | --- | --- |
| 中间行的上方也带圆角 | `position` 全传成了 `Single` | 按 3.2 给 Top / Middle / Bottom |
| 卡片贴在一起、投影叠成一坨 | 少了 `SmartisanListVerticalGap()` | 每个分组之间补一条 |
| 页面发「糊」、条纹底纹不见了 | 给分组传了不透明 `color` | 去掉 `color`，让行自己画卡片 |

## 4. 页面配方

每一节都是「用途 + 用哪些组件 + 关键代码 + 坑」，代码可以直接复制。

### 4.1 设置页

用 `SmartisanGroupItem` 配现成的行组件：开关 `SmartisanSwitchRow`、单选 `SmartisanRadioRow`、
右侧箭头 `SmartisanListRowArrow`。

```kotlin
SmartisanSectionTitle("显示")
SmartisanGroup {
    SmartisanGroupItem(SmartisanGroupRowPosition.Top, "亮度", summary = "自动")
    SmartisanSwitchRow(
        text = "护眼模式",
        summary = "降低蓝光",
        checked = eyeCare,
        onCheckedChange = { eyeCare = it },
        position = SmartisanGroupRowPosition.Bottom,
    )
}
```

`SmartisanSwitchRow` 的 `position` 直接把底图切到对应的那一段，外面不用再包一层。

### 4.2 列表页

```kotlin
Box(Modifier.fillMaxSize()) {
    val listState = rememberLazyListState()
    LazyColumn(
        state = listState,
        modifier = Modifier.fillMaxSize().smartisanVerticalScrollbar(listState),
    ) {
        item { SmartisanListVerticalGap() }
        itemsIndexed(contacts, key = { _, c -> c.id }) { index, contact ->
            SmartisanListItem(
                title = contact.name,
                summary = contact.phone,
                showDivider = index != contacts.lastIndex,
                leading = { SmartisanIcon(res = contact.icon, contentDescription = null) },
                onClick = { /* ... */ },
            )
        }
        item { SmartisanListVerticalGap() }
    }

    // 右侧字母索引
    SmartisanLetterIndexBar(
        letters = contacts.map { it.name.first() }.distinct(),
        onLetterSelected = { letter ->
            val index = contacts.indexOfFirst { it.name.first() == letter }
            if (index >= 0) scope.launch { listState.scrollToItem(index + 1) }
        },
        modifier = Modifier.align(Alignment.CenterEnd),
    )

    // 空态
    if (contacts.isEmpty()) {
        SmartisanEmptyHint(
            title = "没有联系人",
            description = "点击右上角新建",
            actionText = "新建联系人",
            onActionClick = { /* ... */ },
        )
    }
}
```

- **拖动排序**：`SmartisanReorderableColumn(items, onMove = { from, to -> ... }) { index, item, dragging -> ... }`；
- **侧滑删除**：`SmartisanSwipeToDelete(onDelete = { ... }) { row }` —— 行是前景，必须不透明
  （用 `SmartisanListItem` 或自己画底图的行；行里不要留透明区域，否则删除面板会透出来）；
- **分组 + 粘性标题**：用 `LazyColumn` 的 `stickyHeader`，标题换成 `SmartisanLetterSectionTitle`
  或 `SmartisanListBoardSectionTitle`；
- `scrollToItem(index + 1)` 里的 `+ 1` 是列表顶部那条 `SmartisanListVerticalGap()` 占的位置。

### 4.3 详情页（含底部操作栏）

```kotlin
SmartisanScaffold(
    titleBar = { SmartisanTitleBar(title = "专辑", navigationIcon = backAction) },
    bottomBar = {
        SmartisanBottomBar(
            items = listOf(
                SmartisanBottomBarItem(label = "播放", iconRes = SmartisanOriginalIcons.Play),
                SmartisanBottomBarItem(label = "收藏", iconRes = SmartisanOriginalIcons.FavoriteAdd),
            ),
            selectedIndex = tab,
            onSelected = { tab = it },
        )
    },
) {
    Column(Modifier.verticalScroll(rememberScrollState())) {
        SmartisanListVerticalGap()
        SmartisanCard {
            // 封面 + 标题 + 副标题
        }
        SmartisanListVerticalGap()
        SmartisanGroup {
            SmartisanGroupItem(SmartisanGroupRowPosition.Single, "曲目", summary = "12 首")
        }
        SmartisanListVerticalGap()
    }
}
```

`SmartisanBottomBar` 默认自己带导航栏留白（`includeNavigationBar = true`）；
如果你把它当 `bottomBar` 传给 `SmartisanScaffold`，记得把 `applyNavigationBarInset` 传 `false`，
否则留白会翻倍。

### 4.4 表单页

```kotlin
Column(
    Modifier
        .fillMaxSize()
        .verticalScroll(rememberScrollState())
        .imePadding(),          // 键盘弹起时整体上移
) {
    SmartisanListVerticalGap()
    SmartisanGroup {
        SmartisanGroupItem(
            position = SmartisanGroupRowPosition.Top,
            title = "名称",
            trailing = {
                SmartisanClearableField(
                    value = name,
                    onValueChange = { name = it },
                    placeholder = "必填",
                    modifier = Modifier.width(180.dp),
                )
            },
        )
        SmartisanGroupItem(
            position = SmartisanGroupRowPosition.Middle,
            title = "密码",
            trailing = {
                SmartisanPasswordField(
                    value = password,
                    onValueChange = { password = it },
                    revealPassword = revealed,
                    onRevealPasswordChange = { revealed = it },
                    modifier = Modifier.width(180.dp),
                )
            },
        )
        SmartisanGroupItem(SmartisanGroupRowPosition.Bottom, "备注", summary = "可选")
    }
    SmartisanListVerticalGap()
    SmartisanButton(text = "保存", onClick = { /* ... */ })
    SmartisanTextButton(text = "取消", onClick = { /* ... */ })
}
```

- 长文本输入用 `SmartisanMessageField`（自带发送键与左图标槽位）；
- 标题栏里的搜索用 `SmartisanSearchBar(query, onQueryChange)`；
- 坑：输入框放在行右侧时用 `Modifier.width(...)` 定宽，别让它自己撑满 —— 行的右槽只有 6dp 边距。

### 4.5 多选编辑页

```kotlin
var selected by remember { mutableStateOf(setOf<Long>()) }
SmartisanScaffold(
    titleBar = {
        SmartisanTitleBar(
            title = if (selected.isEmpty()) "全部歌曲" else "已选 ${selected.size} 项",
            navigationIcon = SmartisanTitleBarAction(SmartisanOriginalIcons.Back, "返回", onBack),
            actions = listOf(
                SmartisanTitleBarAction(SmartisanOriginalIcons.MultiSelect, "多选") { editing = true },
            ),
        )
    },
    bottomBar = {
        if (editing) {
            SmartisanBottomBar(
                items = listOf(
                    SmartisanBottomBarItem(label = "删除", iconRes = SmartisanOriginalIcons.Delete),
                ),
                selectedIndex = -1,
                onSelected = { /* ... */ },
            )
        }
    },
) {
    LazyColumn {
        itemsIndexed(songs, key = { _, s -> s.id }) { index, song ->
            SmartisanListItem(
                title = song.title,
                summary = song.artist,
                selected = song.id in selected,        // 原版浅蓝多选高亮
                showDivider = index != songs.lastIndex,
                onClick = {
                    selected = if (song.id in selected) selected - song.id else selected + song.id
                },
            )
        }
    }
}
```

### 4.6 弹层与浮层

| 场景 | 组件 |
| --- | --- |
| 确认 / 提示 | `SmartisanConfirmDialog(onDismissRequest, title, message, onConfirm)` |
| 自定义内容 + 按钮 | `SmartisanDialog(onDismissRequest, title, confirmText, dismissText, onConfirm)` |
| 底部菜单 | `SmartisanMenuDialog` + `SmartisanMenuItem(text, onClick, danger = ...)` |
| 底部弹层（内容自己排） | `SmartisanBottomSheet(onDismissRequest, title)` |
| 模态整页 | `SmartisanModalPageTransition(visible = ...)` |
| 轻量提示条 | `SmartisanSnackbarHost(state = ...)` + `rememberSmartisanSnackbarState()` |
| 转圈 / 进度 | `SmartisanProgressDialog`、`SmartisanCircleProgress` |

坑：弹窗与弹层都自己消费返回键，不用你写 `BackHandler`。

### 4.7 时钟与机械控件

- 机械表盘：`SmartisanAnalogClock`（大）、`SmartisanCompactClock`（小）；
- 滚轮：`SmartisanWheelPicker(items, selectedIndex, onSelectedIndexChange)`；
- 标尺：`SmartisanRulerPicker`、`SmartisanPullRingRuler`；
- 星期：`SmartisanWeekdayPicker`、`SmartisanWeekdayChips`；
- 翻页钟：`SmartisanFlipClock`（配 `SmartisanFlipClockDrawables` 与 `SmartisanFlipEasing`）；
- 世界时钟：`SmartisanWorldClockCard`。

这些原本是 XML + 自定义 View，库里全部用 Compose Canvas 与 `pointerInput` 重写，
不依赖任何 View 宿主，所以可以直接塞进任意布局。

### 4.8 日历与日期时间

`SmartisanCalendar`（月视图）、`SmartisanDatePicker`、`SmartisanTimePicker`、
`SmartisanDateTimePicker`，对应的 `...Dialog` 版本可以直接弹出来用：

```kotlin
SmartisanDatePicker(
    year = year,
    month = month,
    day = day,
    onDateChange = { y, m, d -> year = y; month = m; day = d },
)
```

## 5. 主题：只改想改的部分

| 想改 | 怎么做 |
| --- | --- |
| 只改几个颜色 | `SmartisanTheme(colors = lightSmartisanColors().copy(accent = Color(0xFF3482FF)))` |
| 只改文字 | `SmartisanTheme(typography = SmartisanTypography(...))`，或读 `smartisanTypography` 后在组件上覆盖 |
| 只改形状 | `SmartisanTheme(shapes = SmartisanShapes(medium = RoundedCornerShape(12.dp)))` |
| 换字体 | `SmartisanTheme(fonts = SmartisanFonts(...))`，`SmartisanFontMode` 决定用原厂字体还是系统字体 |
| 换滚动越界 | `SmartisanTheme(overscrollFactory = null)`（关掉）或传自己的 `OverscrollFactory` |
| 改某个组件的尺寸 | 直接传参数：`contentHeight`、`minHeight`、`contentPadding`、`iconSize`…… |

色板 / 文字样式 / 形状的完整取值见[主题与设计变量](主题与设计变量.md)。
读数用 `LocalSmartisanColors.current` / `LocalSmartisanTypography.current`，或者
`smartisanColors` / `smartisanTypography` / `smartisanShapes` 这三个只读访问器。

## 6. 素材、图标与对齐

三类对象，按「我需要什么」挑：

| 对象 | 内容 | 怎么用 |
| --- | --- | --- |
| `SmartisanOriginalIcons` | 按用途命名的常用图标（约 90 个） | `SmartisanIcon(res = SmartisanOriginalIcons.Play, contentDescription = null)` |
| `SmartisanDrawables` | 组件默认用的底图 / 图标 / 面板 | 直接传给组件的 `@DrawableRes` 参数，或自己用 |
| `SmartisanIconSet` | 3617 个图标的**总表**，9 组 | 按名字查：`SmartisanIconSet.find("btn_more_selector")`；组内查：`SmartisanIconSet.listRow.find("setting_item_icon_pencil")` |

- 每个条目都是 `SmartisanIconEntry(name, res)`，`SmartisanIconGroup(title, icons)` 是一组，
  `SmartisanIconSet.groups` 是全部 9 组、`SmartisanIconSet.size` 是总数；
- **图标对齐是槽位决定的，不是图标大小决定的**：列表行左槽固定 60dp，图标在槽里居中，
  所以 24dp 与 36dp 的图标后面，标题都从距屏幕左 72dp 开始（`SmartisanListItem` 的 KDoc 有对照表）；
- 想换成自己的素材：所有组件的素材入口都是 `@DrawableRes` 参数，
  传自己的资源即可；整体替换可以只保留代码、删掉 `library/ui/src/main/res/drawable*`，
  再把 `SmartisanDrawables` / `SmartisanIconSet` 指向你的资源。

**夜间资源**：应用内主题与系统 uiMode 不一致时（例如应用内切深色但系统还是浅色），
用 `smartisanThemedResources` 取按应用主题解析过的 `Resources`，
`smartisanWantsNightResources` 判断当前是否要夜间资源，
`smartisanColor` / `rememberSmartisanStateListColor` 解析 selector 里的颜色状态列表。

## 7. 交互与动效

| 想要的效果 | 用什么 |
| --- | --- |
| 无涟漪点击（自绘按压态） | `Modifier.smartisanClickable { ... }`，或自己用 `rememberSmartisanInteractionSource()` + `collectSmartisanPressedAsState()` |
| 系统点击音效 / 虚拟按键触感 | `smartisanClick { ... }` / `smartisanHaptic()` |
| 按压时换文字颜色 | `smartisanPressedTextColor(normal, highlight, pressed)` |
| 复选框的 48dp 命中区 | `smartisanCheckboxHit()` |
| 等宽数字样式 | `smartisanNumericStyle(fontSize)`（机械数字用原厂 `SmartisanClock` 字体） |
| 滚动越界回弹 | 主题默认已提供；单块区域用 `Modifier.overscroll(...)`，或自定义 `SmartisanOverscrollFactory` / 读 `SmartisanOverscrollDefaults` |
| 页面转场 | `SmartisanPageTransition`（常规）、`SmartisanModalPageTransition`（模态） |
| 滚动条 | `Modifier.smartisanVerticalScrollbar(state)` |
| 分组卡片底图（自绘行时用） | `smartisanGroupRowBackground(position)` / `smartisanGroupRowShadow(position)` |

按压反馈**不用涟漪**是刻意的：原版是换色 / 位移 / 缩放，Material 的涟漪一出现就不像锤子了。

## 8. 多语言与文案

- 库内 22 条字符串随系统语言切换，你不用管；
- 自己应用的文案照常放 `values-*/strings.xml`；
- 演示 / 截图需要锁语言时覆盖 `attachBaseContext`（代码见[快速开始](快速开始.md#11-多语言)）；
- 新增组件时：**用户可见文案一律走 `stringResource`**，默认语言放
  `library/ui/src/main/res/values/smartisanx_strings.xml`，并至少补中（简繁）日韩。

## 9. 辅助 API 速查

这些是「不显眼但有用」的一批，平时用得上的时候不用去翻源码：

| API | 用途 |
| --- | --- |
| `SmartisanSwitchStyle` | 开关的两种样式（音乐 / 时钟），原版两套滑块长度不同 |
| `SmartisanSnackbarData` | 提示条当前内容（文案 / 操作按钮 / 时长），`SmartisanSnackbarState.current` 的类型 |
| `SmartisanIconEntry` / `SmartisanIconGroup` | 图标总表的条目与分组类型（见第 6 节） |
| `SmartisanBlankDefaults` | 空态页的默认尺寸与文案（`SmartisanEmptyHint` 用） |
| `SmartisanCircleProgressDefaults` | 圆形进度的默认直径与线宽 |
| `SmartisanMarqueeDefaults` | 跑马灯默认速度与间隔 |
| `SmartisanSpinnerDefaults` | 下拉选择器默认尺寸 |
| `SmartisanInputDefaults` | 输入框默认高度与清除按钮尺寸 |
| `SmartisanSnackbarDefaults` | 提示条展示时长 |
| `SmartisanProgressDialogDefaults` | 进度弹窗默认尺寸 |
| `SmartisanBhmDefaults` | 多选弹层默认尺寸 |

写自己的组件时优先复用这些默认值，这样和库里其他组件保持同一套手感。

## 10. 常见坑（症状 → 原因 → 解决）

| 症状 | 原因 | 解决 |
| --- | --- | --- |
| 组件抛「未找到 SmartisanColors」 | 没包 `SmartisanTheme` | 在 `setContent` 最外层包上 |
| 页面底部内容被系统栏挡住 | 自己处理了 Insets 或用了 `applyNavigationBarInset = false` | 用 `Modifier.windowInsetsPadding(WindowInsets.navigationBars)` 自己补 |
| 键盘弹起挡住输入框 | 没有 IME Insets | 内容加 `Modifier.imePadding()` |
| 卡片圆角出现在中间行 | 行的 `position` 给错 | 见 3.2 |
| 卡片之间的投影糊成一坨 | 缺 `SmartisanListVerticalGap()` | 每个分组之间补一条 |
| 页面看起来「平」、没有条纹 | 给分组传了不透明 `color`，或 `SmartisanScaffold` 传了 `backgroundRes = null` | 去掉 `color` / 用默认底纹 |
| 侧滑删除时删除面板透过行露出来 | 行是前景且必须不透明 | 用自带底图的行（`SmartisanListItem`），别让行留透明区域 |
| 深色下部分素材还是浅色 | 原版只有约 2.5% 的素材带夜间变体 | 已知限制，深色是实验性功能 |
| 应用内切深色后图标不对 | 资源按系统 uiMode 解析 | 用 `smartisanThemedResources` / `smartisanWantsNightResources` |
| 启动器图标变成一张指南针 | 把 `mipmap-anydpi-v26` 改名成了 `mipmap-anydpi` | 保留 `-v26`（见 `sample/lint.xml`） |
| 列表快速点击时按压态「闪一下就没」 | 用了 `interactionSource.collectIsPressedAsState()` | 换 `collectSmartisanPressedAsState()`，它保留同帧快速点击的按压态 |

## 11. 真机核对流程

改组件之后不要只看「编译过了」—— 这套库的验证标准是**真机逐像素核对**。

测试机：nubia P0110，1264×2800 @560dpi（**1dp = 3.5px**）；另有坚果 R2（1080×2340 @400dpi，
1dp = 2.5px）用来对照原版。

```bash
# 1) 安装（P0110 上直接 adb install -r 会卡住，用 push + pm install）
adb push sample/build/outputs/apk/debug/sample-debug.apk /data/local/tmp/s.apk
adb shell pm install -r -t /data/local/tmp/s.apk      # 屏幕上会弹 USB 安装确认框，点 ACCEPT

# 2) 这台机器的 AOD 很激进：息屏后会回到 Dozing + NotificationShade
adb shell input keyevent 224        # 唤醒
adb shell input swipe 632 2200 632 700 200   # 上滑
# 输 PIN → 确认焦点是目标 Activity 再截图
adb shell dumpsys window | grep mCurrentFocus

# 3) 拿控件 bounds 比猜坐标可靠
adb shell uiautomator dump /sdcard/p.xml && adb shell cat /sdcard/p.xml

# 4) 截图 + 量像素（ImageMagick 逐列扫色带，看颜色分段与边界）
adb shell screencap -p /sdcard/pg.png && adb pull /sdcard/pg.png /tmp/pg.png
magick /tmp/pg.png -crop 1x800+100+250 +repage -colorspace gray txt:- | head
```

改完记得把临时文件删掉（`/sdcard/*.png`、`/data/local/tmp/*.apk`、探针 xml），
并把动过的设备设置还原。

## 12. 往库里加组件：约定

1. **放对包**：`library/ui/src/main/kotlin/cc/wuersan008/smartisanx/ui/<分类>/`，
   分类按现有八类（basic / control / input / layout / list / overlay / clock / asset）挑；
2. **命名**：公开 API 一律 `Smartisan` 前缀（`smartisan*` 小写留给 `Modifier` 扩展与工具函数）；
3. **KDoc 必写**：写清楚「对应原版哪个资源 / 布局」「实测数值」「什么时候别用它」，
   并交叉引用容易混淆的兄弟组件；
4. **素材照抄原版**：能用原版 NinePatch / 位图 / selector 就不要自绘，
   入口做成 `@DrawableRes` 参数并给默认值；
5. **用户可见文案走资源**，默认语言放 `values/smartisanx_strings.xml`；
6. **加进示例应用**：在对应页面里展示（`sample/src/main/kotlin/.../pages/`），
   并在 `docs/组件总览.md` + `docs/Components.md` 补上 API 与参数；
7. **跑门槛**：`./gradlew lintDebug`（三个模块都必须 `No issues found.`）+ `python3 tools/doc_audit.py --check`
   （必须「全部一致。」）；
8. **真机核对**并把实测值补进 `docs/组件核对记录.md` + `docs/ComponentVerification.md`（成对更新）。

# 固件组件清单与缺口

坚果 R2 官方固件转储：<https://dumps.tadiphone.dev/dumps/smartisan/darwin>
（分支 `qssi-user-11-RKQ1.201217.002-1-dev-keys`）。

这份文档记录对固件里 **Smartisan 自有应用**的排查结果，
用来回答一个问题：除了已经移植的那批，还有哪些 UI 组件没进库。

`system/system/app` 与 `system/system/priv-app` 下带 Smartisan 前缀的应用有 **60 多个**，

| 应用 | 说明 |
| --- | --- |
| `SettingsSmartisan` | **设置**（本次重点，见下） |
| `LauncherSmartisanNew` / `LauncherOrigSmartisan` | 桌面 |
| `KeyguardSmartisan` | 锁屏 |
| `ContactsSmartisan` / `MmsSmartisan` | 联系人 / 短信 |
| `FileManagerSmartisan` / `FilePreviewSmartisan` | 文件管理 / 预览 |
| `CleanerSmartisan` / `SecurityCenter` | 清理 / 安全中心 |
| `IMESmartisan` | 输入法 |
| `QuickSearchBoxSmartisan` | 全局搜索 |
| `Sidebar` / `SmartisanExpandService` | 侧边栏 / 大爆炸一类系统扩展 |
| `CameraSmartisan3` / `MusicPlayer` / `NotesSmartisan` | 相机 / 音乐 / 便签 |
| `AppStoreSmartisan` / `GameStoreSmartisan` | 应用商店 / 游戏中心 |
| `ScreenRecorderSmartisan` | 录屏 |

> 之前只覆盖了其中 12 个（音乐、天气、时钟、日历、计算器、指南针、图库、邮件、短信、便签、录音机、视频）。
> **其余 50 个左右的锤子应用尚未排查。**

## 三、结论

- 库内现有组件在设置应用里**基本都能找到对应**，没有明显漏掉的「基础」组件；
- 真正缺的是**设置类**的复合组件：选项卡片、可展开分组、带标签滑杆、选项选择器、贴底确认条、
  图案解锁 —— 这些在设置里都是独立实现，值得合并进库；
- **其余 50 个左右的锤子应用尚未排查**（桌面、锁屏、联系人、文件管理、输入法、安全中心……），
  里面大概率还有更多组件。

## 四、下一步建议

按「复用价值 / 实现成本」排序，建议先做：

1. `SmartisanLabeledSlider`（设置里有 5 处重复实现，合并收益最大）
2. `SmartisanOptionCard` + `SmartisanExpandableGroup`（设置页骨架）
3. `SmartisanOptionSelector`（横排/竖排两套合一）
4. `SmartisanBottomConfirmBar`、`SmartisanLockPattern`
5. 再排查 `LauncherSmartisanNew`、`KeyguardSmartisan`、`FileManagerSmartisan`
